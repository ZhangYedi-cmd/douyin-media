# 画面内容：收尾漫画（第 6 节收尾）

海报式收尾场景：一条椭圆形深灰传送带环道自转，中央是发光的 ∞ 符号和大字标题"Loop Engineering"，下方小字"持续交付 · 自动化 · 闭环迭代"。

环道上六个站点顺时针分布，每站必须有蓝色圆形编号徽章和站名标签，编号 1 到 6 一个都不能缺、不能跳号：

1. "取题机器人"：白色机器人从选题箱里抽卡片。
2. "创作机器人"：机器人在笔记本前写稿录音。
3. "质检机器人"：机器人拿着检查清单打勾。
4. "飞书卡片"：蓝卫衣工程师坐在沙发上，对着手机点两个按钮（此站编号徽章"4"和标签"飞书卡片"必须画出，不可省略）。
5. "发布"：机器人按下发射按钮，小火箭升空。
6. "复盘机器人"：紫色机器人拿放大镜读数据报表，沿环道外圈把一支箭头送回站点 1。

工程师旁边小气泡："每天两次按钮，每周几份报告"。

底部通栏横幅大字："让工程回归创造，让循环持续创造价值 ∞"。
