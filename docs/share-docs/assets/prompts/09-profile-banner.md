# 画面内容：个人主页背景横幅（最终裁切 2000x400，5:1 超宽扁形）

延续 Loop Engineering 封面同一套角色、同一配色体系：暖米白背景（#F7F2E7），蓝黑双色手写感粗体大字，蓝色（#3D5AFE 系）主色点缀，深炭色文字。角色沿用同一位戴眼镜黑发蓝色连帽卫衣工程师，以及圆润可爱的白色机器人。

**关键构图约束**：最终成品会被裁切成极扁的横幅（宽是高的 5 倍），所以所有文字和主体角色必须集中画在画面竖直方向的正中间约 55% 区域内，上下各留约 22% 的纯背景空白边距（不放任何文字或角色的关键部分），防止裁切时切掉内容。整体是单行横向排布，不做上下堆叠。

从左到右单行排布：

1. 最左侧（约占 20% 宽度）：蓝色连帽卫衣工程师半身像，戴眼镜，自然微笑，手边一台笔记本电脑（屏幕上一个 `</>`  图标），姿态随意放松（例如单手插兜或抱臂），旁边一个圆润的白色小机器人探出半个身子。
2. 中间（约占 45% 宽度）：账号名大字标题"半亩方塘聊AI"，用与"Loop Engineering"同款的蓝黑双色手写感粗体字，字号要大、清晰可读。
3. 标题正下方一行小字副标语（灰黑色，字号明显小于主标题）："AI 全栈工程师 · 源码解读 · 工程实战 · AI 落地咨询"。
4. 右侧（约占 25% 宽度）：一个小方框徽章，仿照 Loop Engineering 封面右上角徽章样式，框内文字两行"一线大厂"、"AI 全栈"，底部一个小 ∞ 符号。
5. 最右边缘（约占 10% 宽度）：留白，可点缀 1-2 个极简线条小图标（如齿轮、终端符号），不喧宾夺主。

只渲染引号内给定的中文字符串，不要自行添加多余文字，严禁乱码、错别字或英文占位符文本。背景干净、构图疏朗，不要堆叠成海报式高密度漫画，这是一条清爽的个人主页横幅。
