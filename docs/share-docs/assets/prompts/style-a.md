# 风格基座 A：工程漫画风

- 扁平卡通技术漫画插画，暖米白/奶油色背景（#F7F2E7），干净的深色粗描边，柔和平涂上色。
- 固定角色阵容：戴眼镜黑发的年轻中国工程师（蓝色连帽卫衣）；圆润可爱的白色机器人（浅蓝色点缀）；紫色小怪兽代表 bug/故障（反派）。
- 主色：蓝色（#3D5AFE 系）+ 紫色（#7C4DFF 系）点缀，深炭色文字。
- 步骤用蓝色圆形编号徽章；对话用手绘感气泡，内含简短中文；可用小路牌/横幅。
- 画面里的中文必须准确无误、字号大、清晰可读。只渲染引号内给定的字符串，不要自行添加多余文字，严禁乱码或错别字。
- 16:9 横版海报式构图，信息密度高但不杂乱。
