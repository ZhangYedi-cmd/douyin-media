# 风格基座 B：深色技术信息图

- 扁平矢量风格技术架构信息图，深藏青色背景（#101C3A）。
- 顶部居中：白色粗体中文大标题 + 一行灰色小副标题。
- 节点：圆角矩形，细彩色描边（约 2px），内含简洁线性图标 + 大号中文标签 + 一行小字注解。

- 底部一条小图例：绿色方块「输入/数据」、橙色方块「处理/核心」、蓝色方块「输出/结果」。
- 画面里的中文必须准确无误、清晰可读。只渲染引号内给定的字符串，不要自行添加多余文字，严禁乱码或错别字。
