# 画面内容：状态机四节点环形图（第 2 节）

标题："Loop Engineering 状态机"，副标题："配音质检的自愈闭环，最多 3 轮，全程无人"。

四个琥珀橙描边的圆角矩形节点排成环形，顺时针流转，每个节点带橙色圆形编号徽章、一个线性图标、大字标题和一行小字：

- 节点"① 观察"（眼睛图标），小字"死气扫描 + 多音字比对"
- 节点"② 分析"（放大镜图标），小字"逐条归因"
- 节点"③ 执行"（终端图标），小字"重合成 / 注音 / 改文案"
- 节点"④ 验证"（盾牌对勾图标），小字"重新体检"

节点间白色箭头，箭头上挂绿色小药丸标签，依次为："问题清单"（①→②）、"修复方案"（②→③）、"新音频"（③→④）。

出口边有且只有两条，都必须从"④ 验证"节点引出，其它节点不得有出环箭头：一条浅蓝色箭头从"④ 验证"向外出环，标签"PASS 出环"；一条琥珀橙色箭头从"④ 验证"折返回"① 观察"，标签"FAIL 失败重入"。
