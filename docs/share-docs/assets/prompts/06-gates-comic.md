# 画面内容：四格门禁漫画（第 4 节）

2×2 四格漫画，每格细边框、左上角蓝色圆形编号徽章和格标题：

- 格 1，标题"前置闸"：七道小闸门排成一排，门上分别写字母"A"到"G"，一个内容包裹正通过，白色机器人在末端盖绿色印章。
- 格 2，标题"复扫"：一个机器人指着屏幕上绿色的"exit 0"露出放心表情，旁边一台检测仪却红灯大作，仪表上写"64 处死气"，形成反差。
- 格 3，标题"上报"：左侧一本写满求救记号的日志本孤零零没人看；箭头指向右侧，一部手机弹出醒目的飞书卡片，工程师立刻注意到。
- 格 4，标题"降级"：机器人平静地举一块牌子写"余额不足 等充值"，一个内容包裹安静停在停机位上，没有硬闯。

紫色小怪兽可在格 2 和格 3 里客串捣乱。
