# 画面内容：AI 开发工具的四个世代（第 2 节）

顶部标题："AI 开发工具的四个世代"，副标题："从问答到自治循环"。

四个竖版面板并排，每个面板：顶部深蓝色药丸徽章写代数，下方名称，中间漫画场景，复用同一位蓝卫衣工程师和同一款白色机器人：

1. 徽章"第 1 代"，名称"聊天机器人 Chatbot"：工程师在电脑前提问，机器人只在气泡里回答。
2. 徽章"第 2 代"，名称"智能体 Agent"：机器人在笔记本前干活，工程师在它身后探头紧张监督。
3. 徽章"第 3 代"，名称"框架 Harness"：机器人在一个脚手架框架里自主工作，工程师在旁边拿着图纸。
4. 徽章"第 4 代"，名称"循环工程 Loop Engineering"：夜晚，工程师在床上安睡，机器人们围着一个发光的 ∞ 符号自转干活，头顶绿色对勾。

底部通栏横条："☆ 演进趋势：动手做 → 监督者 → 架构师 → 决策者"。
