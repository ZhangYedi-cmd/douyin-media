# docs/ = 只读历史存档

本目录存**会话纪要与设计快照（ADR 性质）**，反映"当时怎么想"，落盘后不更新。

**现行规则不住这里**：找"现在该怎么做"去 `CLAUDE.md` / `brain/` / `pipeline/` / `harness/`。
引用本目录文件时按历史快照对待——与现行文档冲突时，以现行文档为准。

## Iterative-spec/ 目录约定（2026-08-21 起）

- **md 不裸放**。每轮需求迭代新建一个子文件夹，命名 `日期-事项`（如 `0818-看板工作台`、`0821-webvideo-loop`）。
- 子文件夹内文件按 `00-` 序号排：初版方案定稿为 `00-ADR.md`，后续技术方案/实施计划/施工记录依次 `01-`、`02-`…（参照 `0818-看板工作台/`）。
- 早期裸放的历史文档已归 `Iterative-spec/00-架构历史文档/`。
