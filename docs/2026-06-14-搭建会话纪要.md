# 抖音自媒体流水线 · 搭建会话纪要

> 日期：2026-06-14
> 目标：从零搭建一条「选题 → 创作 → 审核 → 发布 → 复盘」的抖音内容流水线，由 Claude Code 原生驱动。

## 一、账号定位（已写入 brain/positioning.md）

- **核心**：AI 方向工程提效实战 + 源码解读（技术深度为主）。
- **辅助**：AI 新闻 / 新模型 / 前沿 skill（流量型，短时效有热度）。
- **配比**：深度 : 流量 ≈ 6:4。
- **形式**：口播视频 + 图文（抖音）。
- **节奏**：工作日 AI 全自动选题→制作→出审，人审后发布；休息日不介入。

## 二、两条地基决策

1. **执行引擎**：Claude Code 原生驱动（skills + 定时 + markdown SOP），不写传统代码。
2. **平台**：只发抖音（"小红书图文"指格式，非跨平台）。

## 三、目录结构（四层：知识 / 流程 / 数据 / 调度）

```
douyin-media/
├── brain/         账号大脑：定位/人设/风格/对标/信息源（AI 每次都读）
├── pipeline/      五阶段 SOP：1选题 2创作 3审核 4发布 5复盘
├── content/       内容条目（数据）
│   ├── _backlog/backlog.yaml   选题池总账（机器读+去重+留痕）
│   ├── _research/              每次调研报告快照
│   └── _template/              新内容骨架
├── automation/    定时 + 编排入口（schedule / daily-run）
├── tools/         第三方工具（social-auto-upload）
├── docs/          会话纪要等
├── dashboard.md   看板
└── CLAUDE.md      项目级规则（人设/红线/skill 约定）
```

**核心设计**：阶段是 `meta.yaml` 里的状态字段，不是目录位置；一条内容的生命周期集中在自己目录，状态机 `idea→picked→producing→review→approved→published→retro_done`。

## 四、已建技能

### 1. douyin-ideate（选题调研，自建）✅ 已试跑验证
- 每 2 天跑：`agent-reach` 抓 AI 圈素材 + 浏览器看抖音平台热点 → 双赛道 6 维打分 → 出报告 + 写选题池。
- 借鉴 `xhs-topic-miner` 的方法论（What/Why/Gap + 机制诊断），但**评分权重重调为抖音版**：深度赛道重「实用+完播」，流量赛道重「时效+惊奇」。
- manual / auto 双模式开关（现在人挑，后期自动挑）。
- **试跑结果**：引擎跑通，10 条选题质量在线（6:4）；据反馈修了 7 处（权重、中英 key 钉死、tags 去重、定位契合微调等）。
- 平台观察通道：最终定为 Claude-in-Chrome 开抖音网页版（computer-use 原生客户端在本机 4K 有指针 gate bug）。

### 2. web-video-presentation（口播视频，外部 copy 入）✅ 已接入
- 口播稿 → 16:9 点击驱动网页演示 → 录屏成片，可选 TTS。
- 画幅决策：**先用 16:9 横屏发抖音，零改造跑通**（竖屏需求按数据再议）。
- 衔接约定：`2-script.md` 为口播稿唯一真相源；它的 Vite 项目放 `build/`，成片 mp4+封面进 `assets/`。

### 3. douyin-publish（自建发布技能）→ 已被 social-auto-upload 取代
- 原设计：Claude-in-Chrome 驱动页面 + computer-use 键盘传文件。保留其安全闸理念（见下）。

### 4. social-auto-upload（第三方发布引擎）✅ 环境已通
- GitHub: dreammis/social-auto-upload，多平台自动发布（抖音/小红书/视频号/快手/B站）。
- **为什么用它**：成熟的抖音上传实现 + 自带官方 Claude 技能 + 一套 `sau` CLI，字段与 `4-publish.md` 完全对齐，远胜手搓 DOM 配方。
- **CLI 契约**：
  - `sau douyin login --account <name>`（扫码登录）
  - `sau douyin check --account <name>`（cookie 校验）
  - `sau douyin upload-video --account --file --title [--desc] [--tags] [--schedule] [--thumbnail] [--headed|--headless]`
  - `sau douyin upload-note --account --images ... --title [--note] [--tags] [--schedule]`
- **环境**：`uv` + Python 3.12 venv（系统默认 3.14 太新，项目要求 <3.13）；`conf.py` 由 `conf.example.py` 拷得；patchright chromium 已装。
- **当前状态**：`uv run sau douyin --help` 已可调用。

## 五、贯穿始终的安全原则

- **发布是唯一对外、不可逆的动作**：永远先把成品/物料备齐 → 人审 → 人审通过=授权这一条 → 才发布。
- 不自动登录 / 不过验证码；不假装成功（结果要从页面确认）。
- 选题"宽进严出"：候选全进池，只高分 Top-N 进创作。
