- 密度：低（复制汇总）。

### 第 8 章：从 AI Coding 到自动化工程

**8.1 从 in-the-loop 到 on-the-loop**
- 结构：五级演进 → 授权默认值 → 可靠反馈通道 → 一次需求端到端走查 → 三种形态 → 小结。
- 开篇：承接前七章，反问"还能不能进一步提效"。收尾：四条要点 + 预告 8.2。

- 引导："你"28 次；1 段授权 Prompt；提问式（"凭什么敢不盯着它"）。
- 密度：高，层层递进无水话。
- 评价：概念定义精准（引擎错配、授权默认值）；纯理论落地感弱。

**8.2 Harness：自动化的基础形态**

**8.3 演化到 human-on-the-loop**

**8.4 Loop 工程**

## 三、跨章共性：这套教程的写作范式

1. **固定五段骨架**（24 篇中 22 篇严格遵守）：承接上节缺口 → 声明本节输入/产出 → 立一个统摄框架（公式/三分法/分层图）→ 分步展开，每步 = Prompt 模板 + 代码/图驻证 + 坑点 → 沉淀为 Skill / CLAUDE.md 规则 → 小结 + 抛给下一节的新盲区。
2. **"盲区接力"式衔接**：开篇首句几乎公式化点名上一节编号与产出，结尾用"X 看不到 Y，下一节补上"过渡。全书仅 6.8→6.9 缺衔接句、7.5 开篇不承接。
3. **"先出清单 → 人工确认 → 再生成代码"** 是第 6 章的标志性套路，在 6.2/6.3/6.4/6.7 原句级复现；第 7 章演化为"AI 生成 + 人工核对清单"；第 8 章升维为"低风险可逆 AI 自行，不可逆停下等人"。同一思想在三章逐级抽象，是全书的隐性主线。
4. **每篇必有一个记忆锚点**：三层防线、分层+增量、双阈值、出错代价公式、三系数乘积、五环闭环、授权默认值、引擎错配、强校验判据。教程不靠知识点堆砌，靠锚点串联。
5. **代码驻证 → 公式驻证 → 数据驻证的迁移**：第 6 章用代码证明（均值 168 行/篇），第 7 章用公式和表格证明，第 8 章用真实运行数据和外部实验（METR、OpenAI）证明。
6. **每章末两篇固定为"方法论收束 + 配置清单"**（6.9/6.10、7.7/7.8），清单篇明示"本节没有新知识点"，把全章打包成可迁移资产。
7. **人称与语气分层**：第 6 章几乎不用"你"（0–2 次），教练式手把手；第 7 章后半和第 8 章"你"激增（7.6 达 37 次），转为顾问式说理。说明越抽象越靠直呼读者拉近距离。
8. **可信度手法**：坑点先行、❌/✅ 对比、明确边界（"AI 给的是假设不是结论"、"什么时候不该引入"）、数据口径标注。整体不夸大 AI。

## 四、值得借鉴与可改进

**可直接借鉴到自有课程的做法**
- 开篇契约（输入是什么、产出四件事、到本节结束时能做到什么），6.4 是范本。
- 结尾不写"总结"而写"下一节要补的盲区"，把读者推向下一篇。
- 一篇一个公式/框架作为锚点，其余内容都归到锚点下。
- 实操篇每个动作三件套：Prompt 模板 + 人工核对点 + 常见坑。
- 章末清单篇：显式列出"跑完本章仓库里该有什么"，可当验收表。

**这套教程自身的短板**
- 清单篇（6.10/7.8）与正文逐字重复，可改为差异对比 + 链接。
- 7.5/7.6、8.2/8.4/长文之间结构同构或内容重叠，连读有既视感。
- 方法论篇（6.1/6.9/8.5）与实操篇切换硬，缺过渡；6.8 缺衔接句；6.7 末尾有残留字符。
- 第 7 章 Vercel、Sentry 特定路径较多，通用性声明与具体命令量不匹配。
- 数据口径不统一：8.4 标注"自报数据"，8.2 与长文未标。
