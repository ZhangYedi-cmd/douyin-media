七根梁，缺一处环就断 — Seven-element closed loop

HEADLINE: 七根梁，缺一处环就断
SUBHEAD: 每根梁接住上游产物，再交给下游

COMPOSITION: 画布中央是一台浅色七段闭环机器，七段环围绕白色中央飞轮；每段都有足够宽的正面标签卡，顺时针连接，禁止做成密集小字仪表盘。

CENTER 标题：Loop

RING NODES（顺时针）：
1. 标题：真相源与状态机｜画面：浅蓝文件账本基座，AI 机器人把数据包放入唯一入口
2. 标题：确定性接口｜画面：浅蓝机械拨杆一次带动多枚空白齿轮
3. 标题：闸口｜画面：黑框眼镜工程师在琥珀色小闸门前确认
4. 标题：调度｜画面：AI 机器人让时钟触发下一段，不在时钟上放文字
5. 标题：反哺回路｜画面：数据箭头从结果端回流到起点
6. 标题：自审与记性｜画面：质检员用放大镜检查账本，旁边是空白教训卡堆
7. 标题：进程管理｜画面：AI 机器人站在终端窗口前拉起一个小型作业进程，进程卡标注最小权限

BREAKPOINT CALLOUT 标题：缺一处环就断
- 在环外画一只小型紫色风险怪兽试图拆走一段连接梁，断口只出现一处红色警示裂纹，不能真的让主环难以辨认

FLOW: 真相源与状态机 → 确定性接口 → 闸口 → 调度 → 反哺回路 → 自审与记性 → 进程管理 → 真相源与状态机
FOOTER BAR: 七要素齐全，系统才能运转、纠偏、进化
LABELS: Loop；真相源与状态机；确定性接口；闸口；调度；反哺回路；自审与记性；进程管理；缺一处环就断
