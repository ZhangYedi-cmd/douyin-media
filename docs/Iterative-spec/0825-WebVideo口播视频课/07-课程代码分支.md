# 07 · 课程代码分支

> 本文定义《WebVideo 口播视频课》配套教学代码的**分支切分**：每个教学分支叫什么、继承谁、覆盖什么功能。
>
> 代码仓库：<https://git.aicodex.cc/devlist/douyin-media>（`douyin-media` 脱敏后的参照仓）。
> 权威来源：`02-模块课程详细设计.md` 各课末尾的分支标注（本文与之对齐；`00-ADR.md` §D5 的旧分支表以本文为准，见 §4）。

## 0. 一句话

**17 个教学分支 + `main`**。一课一分支，按「单点跑通 → 状态机与记账 → 无人值守 → 治理线 → 方法论提炼」五段递进；`main` 是生产仓真身，第 0 课（导览）与第 18 课（结课）不设分支。

## 1. 分支总览

| 模块 | 主题 | 分支 | 覆盖功能 |
|---|---|---|---|
| 一 | 单点跑通 | `01-setup` … `04-review-gate` | 一条内容从网页→配音→成片→终检的完整单链路 |
| 二 | 状态机与记账 | `05-content-factory` … `08-human-review` | 内容资产化 + 唯一记账 CLI + 发布包裹 + 人审双卡 |
| 三 | 无人值守 | `09-daily-run` … `10-alerting` | 编排入口 + 定时任务 + 阻塞上报 |
| 四 | 治理线 | `11-harness` … `14-account-audit` | 治理骨架 + 调度器 + 大环复盘 + 元层自审 |
| 五 | 方法论提炼 | `15-lessons-memory` … `17-console-ui` | 踩坑沉淀 + 看板后端 + 看板前端 |

分支命名规则：`NN-<slug>`，`NN` 为两位序号，`slug` 为短横线小写，与课程编号一一对应。

## 3. `main` 分支角色

- `main` = **生产仓真身**（`douyin-media` 脱敏后的完整参照仓），是全部教学分支的最终形态。
- 教学分支**从 `main` 切出 / 从 `main` 拉指定路径**（链式继承），不是一个独立重写的仓库。
- 第 0 课（课程介绍与目标）与第 18 课（结课）**不设代码分支**：第 0 课只做导览，第 18 课回到 `main` 总览全貌。

## 4. 版本对齐与执行注意

1. **权威来源**：本文与 `02-模块课程详细设计.md` 的分支标注对齐；`00-ADR.md` §D5 的旧分支表（15 分支、`14-meta-audit`、正课只到 16）为早期版本，**以本文为准**（17 分支、`14-account-audit`、正课到 17）。后续若再改，须三处同改并在此登记。
2. **orphan 起步**：`01-setup` 用 `git checkout --orphan` 起最小骨架，让第 1 课「从零搭目录」干净、不带历史包袱。
3. **链式继承**：后续每个分支用 `git checkout <prev> -- <path>` 从上一分支拉所需文件，保证「每课只新增一块、diff 可读」，用相邻分支 `git diff` 做教学对照。
4. **维护纪律**：补丁/纠错从上游分支沿链 merge 下传（merge-chain），不得跳段落单独改下游分支。
5. **安全红线（脱敏）**：教学分支不得包含 cookie、API key、`.env`、corp 关键词；付费依赖只在分支里留配置模板（如 `tts.config.json` 模板化）。**当前 `main` 尚未脱敏**——开课切分支前，必须先完成 `loop-arch-reference` 主干的脱敏清扫，再动手。
