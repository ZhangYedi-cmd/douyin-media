## 部分边界与共享契约（三份执行方案与评审共同遵守）

1. **五包一仓**：`tools/console/`（独立 git 仓，npm workspaces）= `core` / `cli` / `cc-stream` / `server` / `ui`。
2. **core 纯函数**：仅依赖 `yaml` 包；`buildSnapshot(root)`、`computeAlerts(snapshot, now)`；writer 用 `yaml` Document API 点位编辑（禁 js-yaml dump 整篇重写）。
3. **写路径纪律**：全系统状态写入唯一入口 = `media` CLI（唯一 import writer.ts 的包）。server 永不直接写文件：快写 = `execFile("media", [...])`，慢作业 = `spawn claude -p`；server 禁止 import writer.ts。
4. **cc-stream 零依赖叶子包**：三层解析（transport → 6 种归一事件 `started|tool|toolDone|say|stalling|done` → 里程碑引擎），里程碑匹配表由调用方注入（「引擎进包，知识留外」）。信任层级：模型文本只展示、工具事件驱动步骤条、文件状态是唯一裁决。
5. **API 契约**（后端方案 §10 为准）：读 `GET /api/{overview,contents,content/:slug,backlog,harness,metrics}` + `/api/file` `/api/asset` + `/api/health`（带 revision）+ SSE `/api/events`；写 `POST /api/actions/{review,backlog-apply,promote,next-up}`（快写）+ `POST /api/actions/{publish,rework,apply-proposal}`（job runner，202 + 任务 id）+ `GET /api/jobs/:id`。
6. **前端数据层**：只有 `usePageData<T>(url)`（SSE revision 变了重拉）与 `useJob(id)` 两个 hook；ui 对 core 仅 type-only import；无状态库、无图表库。
7. **运行时**：单端口 5170，仅 127.0.0.1 + token；`vite build` 产物由 server serveStatic。
8. **项目铁律不因工作台松动**：发布必须人审；治理线只产报告、人审后应用；`published→retro_done` 是唯一治理线状态迁移；同一规则只写一处（执行方案引用拍板章节号，不复述决策理由）。
