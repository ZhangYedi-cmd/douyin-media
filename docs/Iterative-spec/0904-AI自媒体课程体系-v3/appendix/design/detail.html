你的 Agent 聊三轮就失忆——问题不在模型，在你根本没给它记忆系统。

大部分人搭 Agent，把所有历史消息一股脑塞回上下文，塞满了就截断。这不叫记忆，这叫复读机加健忘症。

真正能用的记忆分三层：会话内的工作记忆，跨会话的事实库，还有一层最容易被忽略的——对用户偏好的沉淀。

这期用一个真实的客服 Agent 例子，把三层怎么分、什么信息进哪层、多久清一次，一次讲清。
