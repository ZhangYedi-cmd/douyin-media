# 第 22 课附录：复盘脱敏样例数据

> 本附录是课程材料，不是任何真实账号的后台数据。数字是编的，但编的时候保证内部自洽：互动率能从点赞、收藏、评论、转发反推出来，转粉率能从涨粉和主页访问反推出来，基线和四条样例的差值都是按传播漏斗的五环模型（曝光→点击→完播→互动→关注）设计的，每条样例都刻意只在一环明显跌破基线，方便第 22 课练手时对号入座。没有自己账号真实播放数据的学员，第 3 节的归因练习就用这份附录；有真实数据的学员直接用自己的，不用看这份附录。

## 一、账号历史均值基线（脱敏样例）

下面这组数字扮演「自己历史均值」这条基线，对应 `.claude/skills/douyin-retro/references/funnel-attribution.md` 里说的三重基准线之一（另外两条是同类作者百分位、同支柱均值，这份附录不模拟这两条，只模拟历史均值）。

| 指标 | 基线值 | 对应哪一环 |
|---|---|---|
| 封面点击率 ctr | 0.16 | 曝光→点击 |
| 2 秒跳出率 bounce_2s | 0.38（越低越好） | 点击→完播 |
| 5 秒完播率 finish_5s | 0.35 | 点击→完播 |
| 完播率 finish_rate | 0.016 | 点击→完播 |
| 平均播放时长 avg_play_sec | 14.0 秒 | 点击→完播 |
| 互动率（(赞+藏+评+转)/播放） | 0.028 | 完播→互动 |
| 转粉率（涨粉/主页访问） | 0.18 | 互动→关注 |
| 涨粉中位数 fans_delta | 7 | 互动→关注 |

## 二、四条样例（7d 窗口数据，脱敏）

### 样例 A · sample-completion-leak（完播环跌破）

| 指标 | 数值 | 相对基线 |
|---|---|---|
| 播放 plays | 6800 | — |
| ctr | 0.17 | 高于基线 |
| bounce_2s | 0.37 | 优于基线 |
| finish_5s | 0.33 | 低于基线（−5.7%） |
| finish_rate | 0.010 | 低于基线（−37.5%） |
| avg_play_sec | 10.2 秒 | 低于基线 |
| 点赞/收藏/评论/转发 | 88 / 80 / 6 / 5 | 互动率 = 179/6800 = 0.0263（低于基线，但不是首个跌破环） |
| 主页访问 / 涨粉 | 32 / 5 | 转粉率 = 15.6%（略低于基线，不是首个跌破环） |

按环核对：ctr、bounce_2s 都优于基线，finish_5s 和 finish_rate 明显低于基线，且 finish_rate 跌幅最大。第一个跌破基线的环是完播，互动率和转粉率虽然也偏低，但那是完播差带来的连带影响，不是各自独立的病因。

### 样例 B · sample-ctr-leak（点击环跌破）

| 指标 | 数值 | 相对基线 |
|---|---|---|
| 播放 plays | 3200 | — |
| ctr | 0.08 | 低于基线（−50%） |
| bounce_2s | 0.35 | 优于基线 |
| finish_5s | 0.37 | 优于基线 |
| finish_rate | 0.019 | 优于基线 |
| avg_play_sec | 15.5 秒 | 优于基线 |
| 点赞/收藏/评论/转发 | 42 / 38 / 3 / 2 | 互动率 = 85/3200 = 0.0266 |
| 主页访问 / 涨粉 | 18 / 4 | 转粉率 = 22.2%（高于基线） |

按环核对：ctr 跌幅最大，其余四环全部优于或接近基线。点进来的人留得住、看得完、还愿意关注，问题出在没多少人点进来，第一个跌破基线的环是点击。

### 样例 C · sample-follow-leak（关注环跌破）

| 指标 | 数值 | 相对基线 |
|---|---|---|
| 播放 plays | 9100 | — |
| ctr | 0.19 | 高于基线 |
| bounce_2s | 0.34 | 优于基线 |
| finish_5s | 0.39 | 优于基线 |
| finish_rate | 0.020 | 优于基线 |
| avg_play_sec | 17.0 秒 | 优于基线 |
| 点赞/收藏/评论/转发 | 260 / 230 / 18 / 24 | 互动率 = 532/9100 = 0.0585（远高于基线） |
| 主页访问 / 涨粉 | 54 / 5 | 转粉率 = 9.3%（低于基线，−48%） |

按环核对：曝光到互动全部优于基线，互动率还是基线的两倍多，只有转粉率明显低于基线。这条内容让人看完了、也点赞收藏了，但没给出关注的理由，第一个跌破基线的环是关注，不是前面任何一环。

### 样例 D · sample-small-sample（小样本，只登记不归因）

| 指标 | 数值 | 相对基线 |
|---|---|---|
| 播放 plays | 410 | — |
| ctr | 0.22 | 高于基线 |
| bounce_2s | 0.30 | 优于基线 |
| finish_5s | 0.44 | 优于基线 |
| finish_rate | 0.028 | 优于基线 |
| avg_play_sec | 19 秒 | 优于基线 |
| 点赞/收藏/评论/转发 | 9 / 6 / 1 / 0 | 互动率 = 16/410 = 0.039 |
| 主页访问 / 涨粉 | 3 / 1 | 转粉率 = 33.3% |

这条样例每一环的百分比都比基线好看，但播放量只有三位数。参考流水线的任务卡把这条判据写得很直接：播放量三位数时，漏斗百分比全是噪音，别过度归因。这条样例只用来演示「什么时候该停手不归因」，不作为「哪种打法更好」的证据用。
