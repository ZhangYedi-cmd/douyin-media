# 写作背景包：动笔前必读

你在写《AI 自媒体流水线》课程 v3 的一课。全书 33 课，你只写其中一课，但要知道全书在干什么。

## 1. 这套课要教什么

让学员通过从零搭一条抖音自动化流水线，学会怎么跟 AI 干活：掌握和 AI 协作的流程，懂得怎么引导 AI，掌握 Loop 思维和架构设计。抖音只是载体。学完的产物目标是 1:1 实现参考仓库 `/Users/yedizhang/yedi-study/douyin-media`：media CLI、飞书人审闸口、本地控制台、十个自封装 skill、一个子代理、五份阶段契约、brain 五份文件。

四块重点掌握项往厚里写：SPEC CODING、Loop 搭建、CLI 与状态收敛、反哺大环。这四块字数不设限，讲透为准。

## 2. 读者是谁，手上有什么

读者会用 Claude Code 或 Cursor，没做过自动化流水线，认知停在单轮对话。

读者手上没有参考仓库。他只有课文，和前几课自己做出来的东西。`plan/inventory.md` 列了每一课结束时学员手上应该有什么，写本课之前查一遍：本课每一条 Prompt 的输入，必须是那张表里本课之前已经出现的东西。让读者「读 pipeline/2-create.md」而他还没写过这个文件，就是错的。这是上一版 15 课被整体退回的原因，不要再犯。

你自己可以读仓库，那是你的材料。但仓库里的信息只能用来保证你写的东西真实存在、判据正确，不能用来替读者补全他没有的前提。你读了源码觉得「这样就懂了」，恰恰说明课文没讲清楚。

## 3. 四条铁律

1. 学员不写一行实现代码。学员写的只有三类东西：中文的需求与判据、SPEC 文档、验收结论。代码、配置、脚本一律由 AI 产出。课文里出现大段代码就说明写偏了。代码块只用来展示「AI 交回来应该长什么样」，供对照。
2. 视频制作本身（怎么剪、怎么配音、多音字和语速、封面怎么画）走一遍流程即可，不深讲。判断标准：这一段讲的是「这个工具怎么用」还是「这类问题该怎么设计」，前者压，后者留。模块 2（07 到 10 课）表面讲配音质检，实际讲 Loop 架构，不属于可精简范围。
3. 零编造。状态值必须在 `tools/console/packages/core/src/state.ts` 里存在；命令、脚本名、文件路径写之前先在仓库 grep；百分比和统计数字要在正文就近给出处，没有出处就删。本仓库的经验值不写成普适规律，三轮上限是项目约定不是统计结论。
4. 禁装逼、禁过度自信、做暖心工程师。这条压过所有写作规则。命中一处整篇退回。具体样子见 `~/.claude/skills/ai-arch-tutorial-style/SKILL.md` 的「成稿绝对不能出现」一节。

## 4. 教法分三档

按有没有互斥的选型、选错了返工贵不贵分档，不按行数。

| 档 | 判据 | 教法 |
|---|---|---|
| L1 轻 | 实现路线唯一；单文件；错了重跑一次 | 一条 Prompt 钉死判据，加三点验收 |
| L2 中 | 多文件或带 references；有约定要定，没有互斥路线 | 一张规格表让学员填，加两三条 Prompt |
| L3 重 | 有互斥路线；跨组件契约；返工贵 | 完整 SPEC 六步：调研、讨论选型、决策、写 SPEC、执行、验证 |

L3 只有三件：media CLI（12 到 16 课）、飞书闸口（18 到 19 课）、控制台（27 到 31 课）。六步的写法由第 11 课钉死，后面七门 L3 课只引用第 11 课，不重新定义。ADR 固定四项：决策、理由、被否方案、反悔成本。里程碑出口条件必须是一句能跑的验证动作。

## 5. 每课长什么样

叙事单元是动作步骤，每课三到六步。每步四段：为什么要这一步；让 AI 做什么（内联一段 10 到 20 行的 Prompt，只针对这一步；产出物有多种可能的先让 AI 出清单，人确认再生成）；拿到结果审哪两三点；出错多半是什么。

开篇一段：承接上一课的产出（具体到产物名、数量、判据）、本课输入、本课产出几件东西。不写痛点故事。每课一个记忆锚点，全篇归到它下面。收尾一两段：本课做到了什么、还看不到什么、下一课补什么。不写「总结与作业」。

一课一个产物：这课结束时学员手上多了什么可落盘的东西，一句话说得出来。每节要有判据或产物，只讲道理的节合并或删。一课 Prompt 超过 5 条就该拆节。

字数不设限，代码行有硬上限：实操 200 行，方法论 30 行。实操篇围栏块至少 3 个，排障句「多半是」至少 2 处。

## 6. 承接

33 课严格按 01 到 33 的顺序写，你拿到的材料第一条是上一课的成稿全文。动笔前先读它的开篇和结尾两段，本课开篇复述上一课产出时按它实际写了什么复述，不按计划。`plan/handoff-ledger.md` 里本课那一行是校验用的：写完拿成稿结尾对一遍，对不上不一定是错，但要当场改台账并在「改过没」列打勾。
