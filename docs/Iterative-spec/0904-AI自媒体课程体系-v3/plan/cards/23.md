## 2.1 大纲

记忆锚点：情报只从外网来，抖音那边的信号靠复盘反向补——选题池自己会烂，得有一条线专门喂它。

开篇契约：上一课交付了 `douyin-retro` skill 和一份复盘报告，发布之后的数据能接回来了；本课输入是学员的 `brain/sources.md`（第 04 课已写好三层词表）、`content/_backlog/backlog.yaml`、`brain/positioning.md`（6:4 配比）；本课产出一个 `douyin-ideate` skill + 一批入池候选。

### 1. 选题池的数据契约：为什么只入不出会烂
- 核心判断：`backlog.yaml` 需要粗粒度三态（idea/picked/published）加过期规则才不会腐化——只入不出的池子会烂，躺久的候选和当下的热点脱节。
- 二级标题：不分
- 交付物：backlog 字段表（id/title/track/format/status/scores/tags/metrics 等）+ `next_up` 指针说明
- 学员此时手上有：第 22 课结束时的 `content/_backlog/backlog.yaml`、`douyin-retro` skill
- 交接：数据契约定了，得有东西真正往里灌

### 2. agent-reach 情报采集：只从外网来，不爬抖音
- 核心判断：抖音主站反爬重，无人值守的流水线爬不动，情报只能从外网来，平台侧的真实信号靠复盘反向补——这不是图省事，是能不能无人值守跑下去的硬约束。
- 二级标题：不分
- 交付物：三层词表复用说明（Layer A 平台体裁词 / Layer B 深度域词 / Layer C 流量信号词，直接引用 `brain/sources.md` 第 04 课已写好的内容）+ `agent-reach doctor` 自检命令核对
- 学员此时手上有：`brain/sources.md`（第 04 课填好的三层词表）
- 交接：情报抓来了，怎么变成一份排好序的选题清单

### 3. douyin-ideate skill 封装：双赛道打分与入池
- 核心判断：深度题和流量题各走一套 6 维打分，但共用同一套抓取引擎——只是权重不同，这样才能既保住深度这条立身之本，又不丢流量破圈的机会。
- 二级标题：不分
- 交付物：规格表（L2）+ prompt 封装 scoring / report 两份 references + `media backlog add` 入池命令说明
- 学员此时手上有：第 2 节的情报清单、`brain/positioning.md` 的 6:4 配比
- 交接：候选入池了，重复题和过期题怎么防

### 4. 去重与清扫：撞题不进池，过期就退池
- 核心判断：30 天主题去重和规则化过期清扫属于记账动作，可以自动做；真正的撞题判断（哪条该留、哪条该并）留给后面的治理任务——那是判断性变更，要人审。
- 二级标题：不分
- 交付物：`media backlog sweep --apply` 命令 + tags 归一化去重规则说明
- 学员此时手上有：第 3 节的入池结果
- 交接：治理线现在有几个任务分头跑

### 5. 选题池养起来之后
- 本课做到了什么：一个能抓料、打分、入池、清扫的 douyin-ideate skill，一批真实入池的候选。
- 还看不到什么：治理任务现在只有复盘和选题两个真正跑通过，还没有人统一排班决定谁先跑。
- 下一课补什么：谁来决定今天该跑哪几个治理任务。
- 结尾抛出的问题：选题池能自己养起来了。四个治理任务各跑各的，谁来决定今天该跑哪几个？

## 共同约束（33 门课一致，不许改写）

> 本课程的目标不是教人做自媒体，是让学员通过这条流水线学会怎么跟 AI 干活：掌握和 AI 协作的流程、懂得如何引导 AI、掌握 Loop 思维与架构设计。抖音只是载体。
>
> 因此：**视频制作本身（怎么剪、怎么配音、怎么调多音字和语速、封面怎么画）一律从简，走一遍流程即可，不做深入讲解。** SPEC CODING、Loop 搭建、CLI 与状态收敛、反哺大环这四块是学员要重点掌握的，往厚里写。
>
> 判断标准：这一段讲的是「这个工具怎么用」还是「这类问题该怎么设计」。前者压，后者留。
>
> 注意别误伤 —— 模块 2 那四课（07-10）表面在讲配音质检，实际讲的是 Loop 架构，配音只是素材，不属于可精简范围。
