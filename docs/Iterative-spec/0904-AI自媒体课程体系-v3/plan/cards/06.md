### 2. 四个位置：信号能落在哪
- 核心判断：验证信号只有四个可能的终点——人、机器、文档、没人管，其中「文档」如果没人主动去读，实际上就等于「没人管」，这是最容易被忽略的一档。
- 二级标题：不分
- 交付物：四位置模型表（位置 / 信号长什么样 / 谁负责推进 / 风险，四行）
- 学员此时手上有：第 1 节的四代对照表（护栏代对应"回给文档"这一档）
- 交接：四个位置摆清楚了，下一节把学员自己流水线上的检查点一条条填进这张表。

### 3. 把自己的契约摊开填表

### 4. 该交给机器的格子，先标出来
- 核心判断：这一课不解决怎么造检测脚本，只解决「哪些格子该交给机器」这个判断，机器要接手，得先有信号可用。
