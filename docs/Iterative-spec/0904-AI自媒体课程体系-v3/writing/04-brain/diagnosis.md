# 诊断结果

## 1. 哪里读不懂

**位置：第 3 节，"这份文件的有效打法那一栏，第一次填上内容是发布近一个月之后，此前空置了二十多天……事情记在 `harness/logs/2026-07-17-retro.md` 这份报告里。"**
问题类型：指代不明 / 读不懂。
为什么是问题：这句话紧跟在"现在一条内容都还没发"（同节上文）之后，突然切到过去式描述一段已经发生、带具体日期的经历，读者分不清这是谁的账号——如果是"你"（读者）的账号，此刻还没发布内容，这件事根本不可能已经发生；如果是作者自己账号的真实历史，文中又没有一个字挑明"这是我自己的账号"。读者读到这里会卡住，不知道这段叙述的主语是谁。

**位置：第 2 节，"Layer B 判层里有没有具体到能检索的词，宽词也留着，它们同时给选题归类当标签，但一层全是宽词就检索不出东西"**
问题类型：概念未解释就用，逻辑内部打架。
为什么是问题：这一句同时说"宽词要留着"又说"一层全是宽词就检索不出东西"，两头都对但没给出留多少算合适的界限。"它们同时给选题归类当标签"这个功能是第一次出现，前面 Layer B 的定义（"对应技术深度支柱的具体技术名词"）完全没提过"标签"这回事，读者不知道这个功能从哪冒出来的。

**位置：第 1 节，"这三层是第 23 课 `douyin-ideate` 要直接用的骨架"**
问题类型：概念没解释就用了。
为什么是问题：`douyin-ideate` 是一个 skill 名字，读者此刻手上没有任何 skill，也没人告诉他这是干什么的东西（读者只在 `CLAUDE.md` 的表格里扫到过这个名字，没有解释）。虽然文中交代了"以后会用"，但对"它现在是什么"没有任何说明，读者读到这里会愣一下。

**位置：第 1 节，persona 表格反例行，"现在就编一句固定开场白，等发现不合适，前面几十条已经这么念完了"**
问题类型：指代不明。
为什么是问题："几十条"没有说清楚是几十条内容还是几十条视频还是几十条稿子，读者要自己脑补。

## 2. 哪里太啰唆

**位置：第 111-115 行，"'不许出现判不了的词'这道审，正反例各摆一条"这整段**
问题类型：同一意思重复三次。
为什么是问题："技术深度和流量型六比四"对"以深度为主兼顾流量"这一组正反例，第 7 行（全文开篇立尺子时）已经用过一次，第 17 行表格里又原样用了一次，到第 111-115 行第三次原样搬出来，没有新增任何信息，只是把前面说过的话再念一遍。

**位置：第 61、116、140 行，三处小节末尾的过渡句**
问题类型：内容与紧跟其后的小标题重复。
为什么是问题："账号是谁、讲给谁听定完了，接下来定它出口时用什么语气说话，素材又从哪来"这句话说完，紧接着的小标题就是"style-guide 与 sources：怎么说话、素材从哪来"，两句话基本是同一句话说两遍；第 116 行和第 140 行是同样的写法，三次重复同一个结构。

## 3. 哪里逻辑断裂

**位置：第 3 节，见维度 1 中第一条**
问题类型：前后矛盾。
为什么是问题：本节开头明确说读者"现在一条内容都还没发"，两段之后又用具体日期讲一段已经发生的"空置了二十多天"的往事，两处对读者当前所处时间点的设定是矛盾的，逻辑链条断在这里。

## 4. 哪里有 AI 味儿

**位置：第 37、59、109、138、168 行，五处"拿到结果审 N 点……如果……，多半是……，回去……"**
问题类型：句式套路、模板感。
为什么是问题：这五处几乎是同一个骨架反复套用（清单 + 一个典型翻车现象 + "多半是"归因 + 纠正动作），读起来像是按同一个模具灌出来的，而不是每次针对具体内容自然生成的判断，模板感很重。

## 5. 哪里在装

无明显违规。逐类扫过标点、直角引号、破折号、金句倒装、导游腔预告、猜心句、俯视腔、作者加戏、表演式标题、黑话堆砌，均未命中禁令清单里的具体写法。唯一值得一提的是第 3 节那处"空置了二十多天"的叙述——它回避了"我""我的账号"这类字眼，但实际功能就是把作者自己的经历当成既成事实端出来，效果上接近作者加戏，只是没有用被禁止的具体措辞，已在维度 3 中列出，此处不重复计分。

## 6. Prompt 块输入是否读者手上真有

六个 Prompt 块本身（positioning、persona、style-guide、sources 关键词矩阵、benchmarks 骨架、tts.config.json）全部合格：每一处引用的 `brain/positioning.md` 都是本课第 1 节先造出来、后面小节才引用，符合"先造后用"的允许顺序，没有要求读者具备清单之外的东西。

问题出在正文而非 Prompt 块里：

**位置：第 3 节，`harness/logs/2026-07-17-retro.md`**
问题类型：引用了读者清单之外、且未交代来源的东西。
为什么是问题：读者手上的 `harness/` 只是骨架目录，没有任何日志文件，正文也没有说明这份报告从哪来、凭什么现在就能引用它。

**位置：第 1 节，`douyin-ideate` skill**
问题类型：引用了读者当前没有的能力（同维度 1 已列，此处仅从"读者清单"角度补充）。
为什么是问题：读者此刻没有装任何 skill，正文没有交代这是第几课才会出现的东西（只说"第 23 课要用"，没说"你现在还没有它"），容易让读者误以为自己漏掉了什么。

## 六维度总结

一、读不懂：主要集中在 benchmarks 那段"空置二十多天"的叙述主语不明，以及 sources 一节里"宽词当标签"这个功能突然冒出来没有铺垫，另有 `douyin-ideate` 首次出现未作解释。二、太啰唆：全文正反例"六比四"对"以深度为主兼顾流量"重复了三次，第 111-115 段基本是纯重述；另有三处小节收尾句与紧接的小标题内容重复。三、逻辑断裂：最突出的问题是 benchmarks 一节前后矛盾——刚说"你还没发过内容"，紧接着又用具体日期讲一段已经发生的往事，读者搞不清叙述的是谁的账号。四、AI 味儿：五个小节里"审 N 点+多半是+纠正动作"的固定骨架反复出现，模板感明显。五、装：逐类扫过禁令清单未命中具体违规写法，唯一存疑处是 benchmarks 段落回避"我"字但实际功能接近夹带个人经历，已并入维度三计分，不重复列。六、Prompt 块本身干净，六个 Prompt 都只依赖读者已有或本课内先造出的东西；问题出在正文引用了读者清单之外且未说明来源的 `harness/logs/2026-07-17-retro.md`，以及未加解释就带出的 `douyin-ideate` skill 名字。
