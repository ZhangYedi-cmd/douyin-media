## 1. 回收：从端到端走查到六页整站
核心判断: 全书锚点收成一条线才有意义，单独看某一课的判断，看不出它在整体里补的是哪个缺口。
支撑材料: 第 01 到 28 课全部成稿的记忆锚点原句与收尾段（analyzed.md 逐课清单）。
交付物: 一张回收表（课号 / 锚点原句 / 在整站里落在哪个环节），28 行全部按各课成稿原句摘录。
二级标题: 1.1 从走查到质检闭环（01 到 10 课）/ 1.2 从 SPEC 到无人值守（11 到 25 课）/ 1.3 从控制台到整站（26 到 28 课）
收尾交接: 全书锚点串成一条线了，接下来要给这条线上留的一个空格补上。

## 2. 四位置模型收尾：验证信号的第三个去处
核心判断: 第 06 课那张四位置模型表留了一格要在这里收，验证信号的第三个去处叫「文档」，这个名字第 06 课已经钉死；第 06 课另有一张四代演进表，第三代叫「护栏代」，两张表说的是两件事，不能混用。

交付物: 一张更新版四位置模型表，把第 26 到 28 课新增的验证点（读 API 全通判据、写路径唯一性判据、六页可看判据）填进对应格子。
二级标题: 不分

## 3. 形态坐标：脚本集合、工作流，还是 agent 系统
核心判断: 这套东西不是三选一，是一条从「脚本集合」到「能自主决策的 agent 系统」的连续轴，当前版本落在中段偏工作流的位置。
支撑材料: 第 24 课治理总调度、第 25 课无人值守闭环、第 28 课整站验收。
交付物: 一张形态坐标表（判据列：谁触发 / 谁判断 / 谁执行 / 出错谁兜底），标出选题、创作、出审、发布、治理五个环节当前各自落点；一条 Prompt 让 AI 按表逐环节标点并说明往下一格挪的前提。
二级标题: 不分
收尾交接: 坐标画完了，接下来要说清楚这套系统里哪些开关不能关。

## 4. 撤档判据：哪些出口一关，系统就退化
核心判断: 这套系统能无人值守跑，不代表可以把所有闸口都关掉，闸口和无人值守是两件事，关错一个闸口，退化的不是效率，是可信度。
支撑材料: 第 17 课人审闸口、第 10 课三轮熔断、第 25 课裁决函数、第 16 课写路径唯一性自证方法。
交付物: 一份撤档判据清单，逐条写「关掉这个出口 → 退化成什么」，覆盖人审闸口、三轮熔断上限、只认文件的裁决、写入口唯一性校验。
二级标题: 不分
收尾交接: 坐标和撤档判据都有了，最后一件事是怎么证明建的这套和课程承诺的功能对等。

## 5. 验收怎么用，加结构项：五条判据
核心判断: 每一项过不了，报告里写的是「你缺的是 X，回第 N 课第几节」，不写扣了几分；结构项问的是「东西在不在、能不能跑」，不问「内容对不对」。
支撑材料: 本课第 3、4 节的形态坐标表和撤档判据；`media check`（第 16 课）；`harness-dispatcher` 与任务注册表（第 24 课）；控制台整站（第 28 课）；自己仓库的 commit 历史或与 AI 的对话记录。
交付物: 一条 Prompt 让 AI 按五条判据逐条给出过/不过判断，不过时附「缺什么 + 回哪一课哪一节」，不许输出百分比或等级；一张验证动作表（判据 / 命令或操作 / 通过标准），五行对齐五条判据。
二级标题: 5.1 验收怎么用：给的是回第几课，不是分数 / 5.2 结构项：五条判据，每条一个能跑的验证动作
收尾交接: 结构项能不能过，机器说了算，内容项就不一样了。
