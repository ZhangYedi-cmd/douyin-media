## 二、终检阶段的主要修改

- 结构遍：五节（含开篇、四节正文）顺序与 outline 一致，标题都是内容描述，不含悬念或数字党。收尾节不叫总结，因为它本身是交付节。
- 论证遍：四件套四种都出现。外部数据（Claude Code 2.1.198/Node 22 门槛、agent-reach 装的六个免登录渠道、20 多个 baoyu skill 只装一个）、权威出处（Claude Code / uv / ffmpeg / 四个开源项目的官方文档，正文就近给链接和取值日期）、真实项目案例（douyin-ideate 不爬抖音的设计、上一课出审判据表里的封面竖版判据）、反例（凭印象写装机命令、ffmpeg 官方页只给静态构建而不是大家常用的 Homebrew）。
- 句子遍：`check_style.py` 的长句警告从初稿的 16 处降到 14 处，重点改了自检基线那一节最长的两句，其余保留的长句多为「几件事按顺序讲完」的枚举句，拆开反而割裂操作步骤，结合语境判断为可接受。
- 温度遍：卡点拦截每节至少一处，四节分别是 Node PATH 没刷新、ffprobe 精简包漏装、sau command not found、环境变量设错终端窗口。松话保留在「这一课下面走的是上面那条 curl 安装，不牵扯这个门槛」「这一课先知道有这回事」两处，句子遍没有磨掉它们。
- 符号遍：`check_style.py` 硬禁令 0，警告 14 处（全部是单句超 80 字，人工判断为枚举句/多分句陈述，非逗号硬拉长句造气势）。
