   **怎么改**：加一句过渡，说明这八条盯的字段是读者第 03 课起就在用的同一批字段，可以当起点用，但字段名要按自己的 `01-ADR.md` 对应过去再抄，不能连名字一起照搬。

   **怎么改**：删掉"在第 12 课调研时列出的"这个定语，改成直接引用读者自己的 pipeline 契约和 skill（这两样是真实存在的材料）。
