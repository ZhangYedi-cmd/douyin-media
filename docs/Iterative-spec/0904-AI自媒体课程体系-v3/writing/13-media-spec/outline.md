## 3. 实施步骤：里程碑怎么切
核心判断: 里程碑不是按代码模块切，是按「能不能拿真实数据跑出一句能验的话」切——参考流水线把 M1 做成读路径 + 两个历史事故最集中的写命令，M2 补齐剩下写命令和存量迁移；这一节的产出构成交付物的第 1 节，且要从学员自己第 12 课的 ADR 推出里程碑边界，不是照抄参考流水线的步骤编号。
支撑材料: `01-CLI执行方案.md` §1 实施步骤表（M1/M2 出口条件原文）；`spec-lesson-standard.md` 的出口条件写法正反例
交付物: 一条让 AI 提出里程碑切分方案的 Prompt + 里程碑表（里程碑 / 做什么 / 出口条件），M1、M2 各一句能跑的验证动作，不写「基本完成」
二级标题: none
收尾交接: 命令拆完、里程碑切完，这份规格已经可以拿去施工了。
