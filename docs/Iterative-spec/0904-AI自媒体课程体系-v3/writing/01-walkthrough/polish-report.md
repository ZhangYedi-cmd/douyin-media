## 二、终检五遍主要修改

1. **结构遍**：标题、各节标题核对无悬念钓鱼、无对仗金句、无数字党；小标题均为内容整体描述。开头改成事实句而非写作意图交代（见上表）。收尾小节"三个固定的位置"是内容判断句，不是"总结/小结"套话。
2. **论证遍**：第 3 节的真实案例改为只引一份文件（`content/2026-07-08/spec-driven-development/meta.yaml`）里真实出现的数字，不再混用另一条内容的数据（早期草稿曾把两条不同内容的注释数字混在一起讲，属于事实拼接，诊断前已自查改正）。反例（七项没查完就推给人）、权威依据（发布契约"发布这个动作做完了收不回来"）、真实案例（上面这条 meta.yaml）三种论证方式都落实到位。
3. **句子遍**：三处单句超 80 字被拆开（起名字那句、案例数字那句、AI 只列两个位置那句），逗号硬拉长句清零；`check_style.py` 警告从 3 处降到 0。
4. **温度遍**：
   - 查缺：五节各自至少一处条件式卡点拦截（如"如果这张表里某一格你现在填不出来""如果流水线跑完既没有产出也没有报错，多半是……"）；留破绽保留"这一课也只是走了个过场"一句，未磨光。
   - 查溢：全文"我"0 次，"咱们"0 次，比喻 0 处（本课不需要），设问 1 次（未使用，属于不硬凑）。
   - 查姿势：导游腔、猜心句、俯视腔、作者加戏、表演式标题逐条核对，未见新增命中；诊断指出的几处已在上表处理。
5. **符号遍**：`python3 ~/.claude/skills/ai-arch-tutorial-style/scripts/check_style.py final.md` 输出"硬禁令清零。警告 0 处"。
