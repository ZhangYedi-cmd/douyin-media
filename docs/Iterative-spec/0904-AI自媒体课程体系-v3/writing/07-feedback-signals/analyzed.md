## 核心问题

一条 Loop（检查、判、改、再量一次，四步自转）要转起来，第一步不是写脚本，是先把"什么信号能写成断言、什么信号只能靠人看"分清楚。本课用配音批次质检当例子，把这件事定成一张六项检查点表（量什么 / 怎么量 / 阈值 / 谁来判），不写脚本，脚本是第 08 课的事。
