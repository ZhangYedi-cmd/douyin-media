支撑材料: analyzed.md 0818 执行版总览条（五包一仓、API 契约）+ card 27 大纲条（快写四条与慢作业三类的精确映射，确保口径一致）+ 仓库真实结构条（已有 core，新增 server/ui）
交付物: `01-ADR.md` 按固定四项写至少四条：①五包一仓边界（core/cli/server/ui/cc-stream，单仓多包，标清哪些已有哪些新增）；②读路径（六个页面各一个快照接口，外加 file/asset/health，变更用 SSE 推）；③写路径两条（快写走 execFile media 子命令同步返回；慢作业走 job runner 返回 202+jobId）；④前端 token 映射（theme.css 的 token 映射进组件库配置，不重新配色）
