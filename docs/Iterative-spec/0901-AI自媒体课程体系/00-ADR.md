# 00-ADR 决策记录：AI 自媒体全流程实战课程体系设计

## 1. 背景与问题
当前很多学习者虽然已经掌握了基础的 AI 工具和单轮对话，但认知依然停留在不断调提示词、手动搬运成果给下一个工具的阶段。
制作一条 2 分钟的视频，往往需要在脚本、配音、录屏、剪辑、发布等环节反复手工操作，人沦为了 AI 工具的外挂。
本仓库已经基于 Claude Code、开源 Skill、自定义质检工具和轻量级 Console 验证了一套高可用、双线闭环的自媒体流水线。
我们需要将这套工程化经验沉淀为一套面向普通开发者的系统课程，引导学员零代码手写搭建属于自己的自动化流水线。

## 2. 课程核心定位与理念

### 2.1 目标受众
- 有一定的 AI 基础，熟悉 ChatGPT、Claude 等大模型对话。
- 认知停留在单轮交互，不知道如何设计自愈反馈闭环（Loop）、不知道如何做自动化质量检测。
- 希望零代码手写、只靠工程设计与提示词协同搭建工业级自动化流程。

### 2.2 教学理念与指导原则
1. **渐进式私教引导**：遵循金字塔原理，自顶向下展开，由浅入深，每个知识点讲透为什么（Why）、是什么（What）和怎么做（How）。
2. **零代码手写原则**：所有代码、配置均通过需求定义与 AI 协同生成，重在培养架构设计与提示词工程心法。
3. **开源优先，少造轮子**：能用开源 Skill（如 web-video-presentation、social-auto-upload、agent-reach）直接复用，只在缺少质量保障和连接机制时指导学员开发自定义工具（如 dubbing-check、feishu-notify）。
4. **开篇先给全景**：第一课先建立全局心智，拆解 10 步端到端流程与难点痛点，再逐个击破。

## 3. 系统技术架构决策

### 3.1 双线闭环模型
- **生产线（pipeline/）**：消费资产，单向流转，停在人审闸口。保证内容生产的稳定性和安全性。
- **治理线（harness/）**：维护资产，定时巡检复盘，只产出优化报告与变更提议，人工核准后回写大脑（brain/），驱动系统自我进化。

### 3.2 质检裁判与选手分离
- 负责生成的流程是选手，负责挑刺的 Reviewer Agent 是裁判。
- 裁判无写文件权限，只出具机器可读的 FAIL 报告与具体修复方案。
- 设置 3 轮循环上限，防止由于幻觉陷入无限修改死循环。

### 3.3 CLI 优先于 MCP 的写入收敛
- 将状态翻转与文件操作收敛至统一的 media CLI 工具。
- 优势：按需加载不占上下文窗口（Context Window）、执行确定性高、容易在多进程和后台作业中复用，彻底杜绝数据状态漂移。
