# 01 课程大纲与知识点设计

```
课程体系总览
├─ 模块 1：破局篇 —— 认知跃迁：从聊天对话到自动化循环
```

## 模块 1：破局篇 —— 认知跃迁：从聊天对话到自动化循环

### 第 1 课：全景蓝图：从一篇文章到全自动视频成片
1. **核心目标**：建立全局认知，明确课程目标与端到端 10 步流程。
2. **核心内容**：
   - 什么是 Loop Engineering，为什么它是解决 AI 返工的唯一途径。
   - 10 步端到端流程中 AI、确定性工具与人类的职责分工。
   - 系统的三大架构亮点与五大实战难点。
3. **产物**：掌握整体架构图，明确各阶段的输入输出契约。

### 第 2 课：状态机思维：如何让验证信号流回 AI 自己
1. **核心目标**：理解 Agent 与 Loop 的根本区别。
2. **核心内容**：
   - AI 工具演进的四个世代（Chatbot、Agent、Harness、Loop）。
   - 观察（Observe）-> 分析（Analyze）-> 执行（Execute）-> 验证（Verify）四步循环。
   - 判断标准：验证信号流向人还是流向 AI。
3. **产物**：设计出第一张属于自己的状态机流转图。

---

## 模块 2：单点篇 —— 开源借力：用开源 Skill 跑通单条内容制作

### 第 3 课：借力开源：5 分钟用 web-video-presentation 做出第一个演示网页
1. **核心目标**：不重复造轮子，快速获得可运行的前端资产。
2. **核心内容**：
   - 开源 Skill 的识别与选型原则。
   - `web-video-presentation` 的输入契约与分段口播稿结构。
   - 如何通过 Prompt 指挥 AI 生成符合短视频节奏的 2-script.md。
3. **产物**：本地生成第一个可点击交互的 16:9 动态演示前端项目。

### 第 4 课：声画组装：接入 tts-dub 与 AI 绘画搞定多媒体资产
1. **核心目标**：完成台词提取、语音合成与封面图生成。
2. **核心内容**：
   - 文案与代码解耦：通过 extract 脚本自动生成 audio-segments.json。
   - 语音配置：`tts.config.json` 的参数解析与音色克隆。
   - 视觉一致性：利用 `baoyu-image-gen` 锁定参考图生成 9:16 竖屏封面。
3. **产物**：完成整套分段 MP3 音频和高清封面图生成。

## 模块 3：质检篇 —— 质量闭环：让 AI 学会自我体检与修复

### 第 5 课：机器判官：用 ffmpeg 打造客观可量化的体检脚本
1. **核心目标**：用确定性工具解决 AI 听不懂音频的问题。
2. **核心内容**：
   - 客观检测 vs 主观评价：利用 `ffmpeg silencedetect` 扫描内部死气。
   - 机器可读的错误清单规范（YAML/JSON 输出）。
   - 引导 AI 编写体检脚本的 Prompt 模板与边界设定。
3. **产物**：完成自动扫描音频异常的 dubbing-check 脚本。

### 第 6 课：裁判与选手分离：用 Prompt 孵化一个只判不改的质检 Agent
1. **核心目标**：避免负责生成的 Agent 产生自我合格的幻觉。
2. **核心内容**：
   - 架构解耦：只读权限的 `dubbing-reviewer` 与负责执行的主流程。
   - 判决规范：要求裁判输出明确的根因与具体修复动作，而非简单打回。
3. **产物**：配置 `.claude/agents/dubbing-reviewer.md` 质检子代理。

### 第 7 课：自愈机制：实现最多 3 轮的自动修复与安全熔断
1. **核心目标**：打通自动修复回路并设置安全上限。
2. **核心内容**：
   - 循环流转：FAIL 携带修复建议 -> 主流程修改配置 -> 重新合成 -> 二次复检。
   - 熔断机制：达到 3 轮仍未通过强制挂起并上报人工。
3. **产物**：跑通首个全自动配音质检与自愈闭环。

## 模块 4：交付篇 —— 状态与安全：人机协作边界与自动化发布

### 第 8 课：安全红线：为什么全自动流程必须停在人审闸口？
1. **核心目标**：建立人机协同的安全边界。
2. **核心内容**：
   - 为什么发布不可逆，AI 只能备齐物料，发布必须人点头。
   - 飞书长连接卡片通知设计：`feishu-notify` 原理。
3. **产物**：在飞书端收到待审视频卡片与点击审批按钮。

### 第 9 课：站在巨人肩膀上：包装 social-auto-upload 为发布 Skill
1. **核心目标**：解决平台上传 DOM 频繁变动的脆弱性。
2. **核心内容**：
   - 开源项目 `social-auto-upload` 的安装与环境隔离。
   - Dry-run 机制：发布前预览最终命令与物料清单。
3. **产物**：实现飞书二次确认后触发自动上传。

### 第 10 课：架构抉择：AI 时代 CLI 为什么比 MCP 更好用？
1. **核心目标**：深入理解工具选型背后的上下文成本与稳定性。
2. **核心内容**：
   - MCP 静态加载带来的 Context Window 浪费。
   - CLI 的懒加载特性（按需查 --help）与高确定性。
   - 人类、脚本、AI 共享同一套 CLI。
3. **产物**：掌握基于 CLI 编排 Agentic Workflow 的设计方法。

### 第 11 课：状态真相源：用 media CLI 彻底告别数据漂移
1. **核心目标**：实现状态机的单点写收敛。
2. **核心内容**：
   - 单一真实源（SSOT）原则：`meta.yaml` 是真相，`dashboard.md` 是派生。
   - 状态机唯一定义：`state.ts` 规范。
3. **产物**：构建统一的 media 记账命令行工具。

## 模块 5：治理篇 —— 系统进化：双线机制与数据反哺

### 第 12 课：熵增危机：为什么没有治理线的自动化流水线必定会烂？
1. **核心目标**：理解资产保养与生产制造的解耦价值。
2. **核心内容**：
   - 生产线只负责消费，治理线专门负责保养。
   - 治理线铁律：只产报告与提议，人工核准后回写 `brain/`。
3. **产物**：搭建账号大脑 `brain/`（定位、人设、风格、对标）。

### 第 13 课：数据反哺：用 douyin-retro 抓取播放数据并诊断归因
1. **核心目标**：用真实受众反馈替代主观假设。
2. **核心内容**：
   - 播放漏斗模型：完播率、互动率、同类基准定位。
   - 将归因结论自动转化为针对 `brain/benchmarks.md` 的修改建议。
3. **产物**：生成标准化的视频复盘与提议报告。

### 第 14 课：源头活水：用 douyin-ideate + agent-reach 搭建智能选题池
1. **核心目标**：实现外网热点素材的自动化采集与打分入池。
2. **核心内容**：
   - 借助 `agent-reach` 抓取海外 X、GitHub、Reddit 前沿技术信息。
   - STEPPS 传播力模型在选题打分中的自动化实现。
3. **产物**：自动更新的 `content/_backlog/backlog.yaml` 选题池。

### 第 15 课：系统总调度：用 harness-dispatcher 实现无人值守巡检
1. **核心目标**：实现治理任务的自动化周期触发。
2. **核心内容**：
   - 声明式任务注册表：`harness/tasks.md`。
   - 事件触发（窗口检测）与周期触发的设计与实现。
3. **产物**：搭建后台巡检调度器，保持系统资产实时保鲜。

## 模块 6：总控篇 —— 全景工作台：不写一行代码打造可视化控制台

### 第 16 课：告别纯黑盒：打造基于 SSE 的本地实时控制看板
1. **核心目标**：提供直观的可视化全局视图。
2. **核心内容**：
   - 单端口轻量架构：Hono 后端 + React 前端 + 本地静态托管。
   - SSE 事件流机制：文件变动感知与前端被动刷新。
3. **产物**：本地启动单端口可视化 Console 工作台。

### 第 17 课：无头长跑：用 claude -p 进程无缝接管后台复杂作业
1. **核心目标**：优雅处理耗时较长的后台生成与发布任务。
2. **核心内容**：
   - 异步 Job 机制：`202 + jobId` 快速响应。
   - `cc-stream` 结构化解析：将子进程终端输出转换为可视化进度。
3. **产物**：在前端看板上一键启动长耗时作业并实时观察进度。

### 第 18 课：心法沉淀：如何成为 AI 时代的超级个体架构师？
1. **核心目标**：总结系统设计心法，实现跨场景能力迁移。
2. **核心内容**：
   - 极简架构原则：文件即存储，CLI 即接口，Markdown 即契约。
   - 边界原则：生成给模型，验证给脚本，决策归人类。
   - 迁移指南：如何将双线架构应用到公众号、周刊或代码巡检场景。
3. **产物**：沉淀个人专属的 AI 架构设计心法手册。
