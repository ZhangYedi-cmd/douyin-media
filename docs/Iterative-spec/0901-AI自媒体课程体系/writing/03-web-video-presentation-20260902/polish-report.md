## 二、终检五遍的主要修改

- 结构遍：标题全部为内容描述，收尾节改名“小结”。开头为事实起手，无大背景。各节交接靠内容（“网页有了，声音还是文字”“分段文案就位”），删掉一处“下一步”式空转。
- 论证遍：每个论点有支撑。冷开规则用 ep12 真实首句；重抽铁律用 lessons L2；余额探测用 L9；漏字幕用 L15；封面用 L1；成片对齐用 ep12 的 137.300 / 137.304 秒；估时 4 字每秒指向 OUTLINE-FORMAT.md。旧稿的 METR 引用与 `window.__READY__` 未沿用。
- 句子遍：被字句改主动（“被这个卡死过”保留一处，属遭受义）；“通过 X 使得 Y”零出现；黑话“对齐”首次出现处保留为 skill 原词 Checkpoint Plan 的白话解释“商量一致”未加，因表格已列五件事。
- 温度遍：每节至少一处条件式拦截（第 2、3.2、4、5、6 节各有“如果……多半是……”或“如果……停下来”）。“咱们”0 次，“我”0 次（JSON 引文内的“我”不计）。留破绽：收尾“反正现在能跑通，撑不撑得久是另一回事”一句口语化收尾，未磨。
- 符号遍：`check_style.py` 硬禁令清零，警告 0。
