## 1. 读不懂
- 第 1 节表格「确认点」列出 Checkpoint Plan 这个英文术语，但直到后文才说明它是 skill 产出 script.md/outline.md 后停下来的那一刻。术语先出现、定义后补，读者第一次看表格时会卡住。
