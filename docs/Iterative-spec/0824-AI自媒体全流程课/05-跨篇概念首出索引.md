# 跨篇概念首出索引

## 这份文件干什么用的

派工任务书里的「可消费概念」只管一篇文章的上游，管不住横向。真实发生过：**只读工具是物理约束**这个判断，在 1.1、1.2、2.3 被从头论证了三遍，三篇作者各自以为自己是第一个讲这件事的人，谁都没引用谁。

这份索引记每个概念**第一次被完整论证**的位置。写作规范 §10.1 规定：动笔前先查这里；已登记的概念只能一笔带过或显式承接，不许重新搭论证脚手架；本篇新立的概念，交付时补进来。

登记位置与实际交付文件对不上时，**以实际交付文件为准**，改索引，不改文章。
