- 对象：`docs/Iterative-spec/0904-AI自媒体课程体系-v3/courses/` 全部 29 课，以及项目现行规则文件
- 状态：七项决策全部定稿（2026-09-06 人已拍板），阶段 1 开工

## 一、背景

外部带入三份材料，构成一套完整的去 AI 味方法论：

| 材料 | 性质 | 作用 |
|---|---|---|
| 写作规范.md | 人读的教训叙事 | 反套路清单、词汇层十条、九个失败案例、语感锚定基线、固定流程九步 |
| 语感样本库.md | 人读的语感靶子 | 按七类句式收录 Claude Code 与智谱官方文档原文例句，回答“官方文档该怎么写” |
| ai-patterns.json | 机器读的模式库 | 24 条正则模式，分 tone 腔调 / syntax 句式 / grammar 中文语法三类 |

材料本身预设了四个配套脚本（`scan-ai.js`、`scan-lexicon.js`、`stats-tech.js`、`lexicon-slice.js`）与一份 `tech-lexicon.json` 词库，这次都没有随材料给到，需要本项目自建或重写。

## 二、实测结论：符号层与统计层的现状

开工前先对 29 课做了一次量化体检，结果决定了这次治理的方向。

统计层与符号层实测（口径：剥离代码块、行内代码、表格、标题、列表标记后统计正文）：

| 指标 | 规范执行标准 | 29 课实测均值 | 判定 |
|---|---|---|---|
| 句均长 | 大于等于 40 字 | 40.1 | 压线通过 |
| 句长标准差 | 大于等于 8 | 20.0 | 远超 |
| 句首去重率 | 大于等于 70% | 90.3% | 远超 |
| 短句占比（碎句化） | 禁通篇碎句 | 7.75% | 健康 |
| 破折号 | 每篇不超过 1 处 | 0 | 通过 |
| 直角引号 | 0 | 0 | 通过 |
| 感叹号 / 省略号 / emoji | 0 | 0 / 0 / 0 | 通过 |

结论一：这套规范里机器能测的那一半，课程已经达标。所以本次治理的性质是定点清除，不做全量重写。

结论二：不为凑句均去拉长句子。01、03、06、09、17、25、26 这七课句均在 32 到 36 字之间，但句长标准差均在 13 以上、短句占比不足 13%，属于长短交错的健康节奏。规范原文写的是“信息完整的长句为主，允许短句点缀”，这七课判定为已达标，不动。

## 三、一个绕过现有检测的句式

`tools/check-lesson.sh:31` 的装腔词表已经收了 `不是[^。！？]{1,30}而是`，命中即 FAIL。课程正文使用的是“不是 X，是 Y”，省掉了“而”字，现有正则抓不到。新模式库的 P007 抓到了，14 个文件共 63 处，`15-执行M2` 一篇 8 处，`07`、`11` 各 5 处。

实例（`courses/06-验证信号流向谁.md`）：

> 自动化系统真正要做的分工，不是让人少干活，是把人从盯着每一步操作的执行者，变成设定目标、看结果、只在出事时才出手的监督者。

这是句式模板脱掉一个字继续用，属于规避检测而非解决问题，与《写作规范》失败案例 2 记录的“把造势式 AI 味换成干脆式 AI 味”同类。修正方向包含两件事：改文，以及把检测补全，防止同一形态再次绕过。

## 五、已定决策

### 决策 1：权威腔“铁律”全部改掉，含项目术语

课程 32 处、项目现行规则文件约 25 处，全部替换为“硬约束”“基本约束”“不可退让的一条”等按语境择一的表述。P020 判 ERROR，不加 exclude。

代价与理由：这会改动 `CLAUDE.md`、`pipeline/` 五份阶段契约、`harness/` 与 7 个 skill 的措辞。人已确认接受牵动项目根文件。

### 决策 2：“不是 X，是 Y”限量到每篇最多 2 处

保留它作为下判据的手段，压掉高密度篇目（`15` 8 处、`07` 与 `11` 各 5 处），其余改写为先给事实再给判断的陈述句。同时把 `check-lesson.sh` 的正则补上无“而”变体，堵住绕过路径。

### 决策 3：口语词按规范改成书面语，并同步改 `check-lesson.sh`

规范第 9 步“口语残留”条款与 `tools/check-lesson.sh:22` 强制要求实操篇有至少 2 处“多半是”排障句方向相反。人已拍板以规范为准，解除脚本对排障句的强制要求。

### 决策 4：标题编号体系改为“一、”与“1.1”

现状实测：`#` 一级标题每篇 1 个已统一（此前看到的多余一级标题全部位于代码块内，是 shell 注释与 md 模板示例，不计）；`##` 二级 165 个中 162 个使用“1.”“2.”，3 个漏编号（`07-反馈信号从哪来.md:110`、`20-发布Skill与dry-run.md:124`、`18-飞书通道SPEC.md:216`）；`###` 三级 63 个全部使用“N.N”，已统一。

改为：`##` 用“一、二、三”，`###` 用“1.1、1.2”，章号与节号并行对应（第一章的小节为 1.1、1.2，第二章为 2.1、2.2）。同时补齐上述 3 处漏编号。

### 决策 5：标题改成陈述性白话，去掉修辞

问题定性：165 个二级标题中 158 个带冒号，冒号后半句普遍在替读者下判断，且动词用力（焊、钉死、判决、砸、拎、压、摊开、倒推）。正文是平实白话，标题层在造气势，两层语气不一致。

改写判据一条：**标题说这一节讲什么，不说这一节的结论是什么。** 结论留在正文，标题只做索引。冒号结构可以保留，但冒号后必须是说明而非判断。

对照示例：

| 现在 | 改后 |
|---|---|
| 4. 跑一次真实判决 | 四、用真实配音跑一轮质检 |
| 2. 工具白名单：把不能改焊进定义里 | 二、工具白名单：限制裁判的修改权限 |
| 3. 裁决口径：保守判 FAIL，输出格式钉死 | 三、裁决口径与输出格式 |
| 2. 造一个样板，照样板批量复制剩下五个 | 二、先写样板脚本，再批量复制其余五个 |
| 1. 四代演进，一刀切法：验证结果回给谁 | 一、四代工具演进与验证结果的去向 |
| 1. 回路怎么接：判、修、复判轮流交棒 | 一、回路的三个角色与交接顺序 |

措辞口径说明：人提出的参考写法“进行一轮质量检查”撞上 P015 动词虚化（“进行 + 名词”属英文语法直译），按《写作规范》规律一，中文动词直接说，故取“跑一轮质检”而非“进行一轮质检”。陈述化与去修辞按人的要求执行，具体措辞服从规范。

## 六、口语词范围与历史存档的决策

### 决策 6：口语词全量改成书面语，含“多半是”

人已拍板取原待定 1 的选项 B：不只改断裂口头语，“多半是”101 处一并改成书面表达。

连带必须同步修改的三处，否则规则会互相打架：

| 文件 | 现状 | 处理 |
|---|---|---|
| `tools/check-lesson.sh:22` | 实操篇“多半是”少于 2 处即 FAIL | 解除该强制要求 |
| `plan/00-写作背景包.md:48` | 写明“排障句「多半是」至少 2 处” | 同步改为书面排障表达的要求 |
| ai-arch-tutorial-style skill | 把排障句“多半是”列为风格特征 | 该 skill 住用户全局目录 `~/.claude/skills/`，改动会影响其他项目，是否同改需人单独确认 |

替换口径不搞一刀切，按词性分三类，落成 `v3/tools/writing/lexicon.json` 供扫描器使用：

| 类别 | 例词 | 处理 |
|---|---|---|
| 业务术语，保留 | 打回、踩坑、坑、熔断、闸口 | 不改。规范原文写明“去 AI 味去的是空洞，不是专业” |

### 决策 7：历史存档不动

`pipeline/logs/`、`content/`、`docs/` 下共 73 个含“铁律”的文件属于历史运行记账，本次不改。依据是 `docs/README.md` 已定义 `docs/` 为只读历史存档、落盘后不更新，改写历史记账没有收益且有篡改记录的风险。

## 九、验收标准

1. 29 课 scan-ai 零 ERROR，P007 每篇不超过 2 处。
2. 统计层各项不退步：句均、句长标准差、句首去重率均不低于本 ADR 第二节记录的基线值。

5. 逐课 diff 可解释：每一处改动能对应到本 ADR 的一条决策，无顺手改动。
6. 标题编号全量为“一、”与“1.1”两级形态，无漏编号，正文一级标题每篇 1 个。
7. 标题层不出现替读者下判断的句子与强修辞动词（焊、钉死、判决、砸、拎、压等），且不引入“进行 + 名词”的动词虚化写法。

## 十、风险

1. **改写引入新别扭**。《写作规范》失败案例 2 与 9 记录过两次：为了示范怎么改，造出比原文更怪的新表达。对策是执行最小改动原则，只改目标句，相邻句保持原样。
2. **术语误伤**。“打回”“踩坑”“铁律”都处在业务术语与腔调的边界上，判错会伤专业性。对策是第六节先拍板分类，再批量执行。
3. **两套规则打架**。项目已有 ai-arch-tutorial-style skill 与 `check-lesson.sh` 两层检测，新规范是第三套。若不在阶段 1 合并口径，后续改写会来回拉扯。对策是阶段 1 一次性收敛到 `check-lesson.sh` 一个入口。
4. **判据句变弱**。决策 2 压缩“不是 X，是 Y”可能让部分判据的对比力度下降。对策是在样板课人审时专门检查这一点。
