# 选题信息源

`douyin-ideate` 技能从这里取"抓哪些源、用哪些关键词检索"。分三类。

## 一、素材源（agent-reach 抓 —— 讲什么有料）

### 流量/时效源
- **X/Twitter**：AI 实验室官号、大佬、新模型发布（OpenAI / Anthropic / Google DeepMind 等）
- **Reddit**：r/LocalLLaMA、r/MachineLearning
- **HackerNews**：AI 相关 Show/Ask/热议
- **官方发布页**：各家模型/产品 release

### 深度/可沉淀源
- **GitHub Trending**：AI / Agent / LLM 工程方向的热门项目
- **arxiv**：值得讲的论文（深度题创作用 `ljg-paper` 衔接）
