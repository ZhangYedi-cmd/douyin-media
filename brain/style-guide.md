# 风格指南

## 标题钩子库（套路，非固定文案）
- 痛点直击：「还在手动 X？一个 AI 工作流省掉 80% 时间」
- 反常识：「都说 X，其实源码里根本不是这么做的」
- 数字清单：「拆完 X 源码，记住这 3 个设计就够了」
- 结论前置：「X 模型最该关注的不是跑分，是这一点」
- 时效蹭热：「X 刚发布，我第一时间扒了它的 Y」

## 口播视频规范
- 时长：30–90s（深度内容可到 2–3min）。
- 结构：钩子(3s) → 主体(分点) → takeaway/互动。
- 字幕：必上，关键词高亮。
- 封面：标题 + 一个视觉锚点（架构图/代码/模型 logo）。

## 图文规范
- 首图即封面，承担钩子。
- 单条 6–12 张以内，一图一观点。
- 配图风格：技术内容用架构图/流程图（`baoyu-diagram`）；
  科普向可用图鉴风（`retro-enc`/`wanwu-series`）。

## 违禁词 / 合规
- 避免绝对化用词（最/第一/100%）与未证实承诺。
- 外部链接不在口播中念，引导走合规话术。
- 敏感词清单：_（待补）_

## 视觉资产
- 统一封面模板：_（待定）_
- 配色 / 字体：_（待定）_
