- **正文/简介**：Claude Code 改一个环境变量，就能让它去跑 GPT、跑 Gemini，而下游干活的那套代码一行都不用动。怎么做到的？我扒了它的源码：难点在于每家大模型的接口、流式协议、工具调用格式全不一样。它的解法特别像同声传译——在 API 层放一个翻译官，把 GPT 吐出来的流式事件逐条翻译成 Claude 自己的内部格式再吐给下游，而且是流式的，每收到一个小片段就当场翻、当场传。翻完之后，下游的循环、工具、界面拿到的永远是同一种格式，压根不知道背后是 GPT 还是 Claude。设计上还有三点讲究：每接一家模型单开一个文件夹、加新模型只需新建目录加一行分发、用哪家由「设置 > 环境变量 > 默认 Claude」决定，源码里一共列了七种 provider。这就是适配器模式落到真实工程里最干净的样子——对扩展开放，对修改关闭。逐行可溯源，系列每天更一期。
