# 封面生成提示词 · 上下文工程

9:16 竖屏封面，画幅比例 1536×2752（或等效 9:16）。

## 整体气质
深色暖调工程/编辑杂志风（midnight-press 美学）：接近纯黑但偏暖的浓咖底色（约 #0d0b09 到 #1a1714），单一热橙色作为唯一强调色（约 #ff4a2b），电影感、克制、有杂志封面的分量感。不是花哨渐变卡通风，是"深夜里拆一个技术问题"的专业气质。可叠加极淡的暖色暗角（vignette），不要噪点颗粒过重。

## 视觉主体（画面中上部）：上下文压缩隐喻
一个"压缩"的视觉：
- 左侧/上方：一大片密密麻麻的小方块（代表海量 token / 上下文），排得又多又乱，用暗灰色，边缘可有几块虚化淡出（象征"塞太多反而记不住"）。
- 中间：这些小方块经过一个收窄的漏斗 / 楔形通道被压缩。
- 右侧/下方：汇聚成一小簇明亮、密实、发热橙光的核心方块（代表压缩后仍保留关键信息的"精华上下文"）。
- 在压缩前后可标注对照数字：大而暗的「10万」 → 收窄后变成热橙高亮的「2万」，中间用一个橙色箭头连接。数字要清晰。
- 整体传达"从庞杂压到精炼、信息没丢"的张力。

## 标题文字（画面下半部，占比最大，承担钩子）
- 顶部小字徽章（胶囊形状，热橙色描边，橙字）："AI 工程提效 · 实战"
- 主标题超大字（暖白色 #f5f0e5，粗体无衬线或衬线均可，视觉焦点）：
  「上下文工程」（四个中文大字，最大字号）
- 副标题（暖白偏灰 / 部分热橙高亮，中等字号，可两行）：
  第一行："把 10 万 token 压到 2 万"
  第二行："还不丢关键信息"（"不丢"两字用热橙高亮）

## 底部
一条热橙色细横线分割，下方留白即可，不需要具体来源文字。

## 文字要求
- 所有中文与数字必须清晰、拼写正确、不糊、不叠字、不乱码，主标题「上下文工程」四个字务必端正可读。
- 数字用阿拉伯数字：10万 写作「10万」，2万 写作「2万」，token 用小写英文。

## 禁止事项
- 不用紫粉渐变、彩虹渐变、赛博霓虹多色。
- 不用卡通形象 / emoji / 拟人吉祥物（本片非系列内容，无需延续任何系列吉祥物设定）。
- 不用真实品牌 logo（Anthropic / Claude / Manus / OpenAI 等一律不出现，避免侵权）。
- 只用"暖黑底 + 暖白字 + 单一热橙"三色系，克制，不要花哨。
- 标题文字必须清晰可读，不被视觉元素遮挡。
