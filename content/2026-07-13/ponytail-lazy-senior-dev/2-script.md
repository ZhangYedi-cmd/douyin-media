## 钩子（冷开）

**[1]** narration：你让 AI 帮你写一个日期选择器。它二话不说，给你装了个第三方库，写了个包装组件，还加了张样式表，然后开始跟你讨论时区该怎么处理。
画面：左侧一坨"AI 热心过度"的文件清单（装库 / 包装组件 / 样式表 / 时区讨论），逐条冒出，气氛越堆越满。

**[2]** narration：可一个干了十几年的老工程师，看一眼，一行就搞定：一个 input，类型写成 date，浏览器自带的选择器就出来了。有个开源项目叫 ponytail，干的就是一件事——把这个「最懒的高级工程师」，塞进你的 AI agent 里。
画面：右侧把左边那坨全划掉，只留一行代码 `<input type="date">`；ponytail 项目名 + 一句话标语「He says nothing. He writes one line. It works.」淡入。

## 点一 · 它改的不是省字，是决策

**[3]** narration：先说清楚，它不是让 AI 少打字、省 token。它给 AI 的，是一套「该不该写」的判断。核心就一句话：最好的代码，是不写的代码。
画面：把"省 token"打叉，"决策 / 该不该写"点亮；中央大字「最好的代码是不写的代码」。

**[4]** narration：但它有条底线，写得明明白白：校验、错误处理、安全、还有可访问性，这四样一个都不许砍。代码变少，是因为本来就不需要那么多，不是偷工减料。
画面：四个"不许砍"的护栏标签（校验 / 错误处理 / 安全 / 可访问性）钉死；底部一行小字「小是因为必要，不是因为偷工」。

## 点二 · 七级阶梯（可直接抄的干货）

**[5]** narration：它最值钱的，是一套七级阶梯。就算你压根不装这个工具，把它抄进你给 AI 的规则里，照样有用。AI 动手之前，从上往下问，停在第一个成立的台阶。
画面：一架七级阶梯的骨架淡入，标题「写代码前，先爬这架梯子」。

**[6]** narration：第一级：这功能，真的需要存在吗？不需要，直接跳过。第二级：代码库里是不是已经有了？有就复用，别重写。第三级：标准库能干吗？第四级：平台原生能力能干吗？
画面：阶梯前四级逐条高亮——①需要存在吗(YAGNI) ②已有?复用 ③标准库 ④平台原生。

**[7]** narration：第五级：已经装好的依赖能干吗？第六级：一行能搞定吗？能，就一行。到第七级，实在没辙了，才写那个刚好够用的最少代码。
画面：阶梯后三级高亮——⑤已装依赖 ⑥一行 ⑦最后才写最少代码；越往下台阶越窄。

**[8]** narration：关键在这一句：这架梯子，是在它读懂问题、读完相关代码之后才开始爬的，不是拿来代替思考。用它自己的话说——对方案偷懒，对读代码，从不偷懒。
画面：高亮「读懂问题 → 再爬梯子」的先后顺序；金句「Lazy about the solution, never about reading.」

## 点三 · 数据，和一个诚实的故事

**[9]** narration：光讲理念没用，我看它给的数据。它是在真实的 Claude Code 会话上测的：改一个真实的开源项目，前端 React、后端 FastAPI，十二个功能任务，同一个 AI，开和不开这个 skill，各跑一遍。
画面：实验设置卡——真实 Claude Code 会话 / full-stack-fastapi-template / 12 个任务 / 同一 agent A-B 对照 / Haiku 4.5, n=4。

**[10]** narration：结果：代码量，少了百分之五十四；token，少百分之二十二；成本，降百分之二十；耗时，少百分之二十七。而且安全项，百分之百没掉。它是唯一一个「四个指标全降、还全程安全」的。
画面：四个数字条动画 -54% / -22% / -20% / -27%，外加 100% safe 徽章；对照组 caveman、纯 prompt 各有指标不降或掉安全。

**[11]** narration：但真正让我觉得靠谱的，是另一件事。它一开始宣传的是「少写百分之八十到九十四的代码」。后来有人提了个 issue，说你这是单发生成、裸模型基线自己灌了一堆废话撑出来的水分。项目方认了，把数字改回公允的百分之五十四。
画面：一个"80–94%"的大数字被划掉，箭头指向"54%"；旁边贴 issue #126 的批注气泡。

**[12]** narration：一个敢当众砍掉自己一半宣传数字的 benchmark，反而更可信。这也是我一直想说的：看到那种特别漂亮的整数大数字，先别激动，先问一句——它拿什么当基线。
画面：金句「先问：它拿什么当基线？」；背景虚化的榜单数字。

## 边界 · 别当银弹

**[13]** narration：当然，它不是银弹。省成本、省时间，是「模型愿意照阶梯走」的副作用。你要是换个特别啰嗦的推理模型，光纠结该爬到第几级，思考的 token 就又烧回去了——这一点，它自己都承认，在某些模型上就会反过来。
画面：一个天平：一边"少写代码"，一边"多花思考 token"；标注「取决于模型是否照阶梯走」。

## takeaway + 互动

**[14]** narration：所以我的建议：工具你不一定装，但这七级阶梯，真值得抄进你给 AI 的规则里，让它写代码前先自己爬一遍。你会发现，那种「热心过度」的过度设计，能少一大半。
画面：七级阶梯定格 + 一行「抄进你的 AI 规则」行动号召。

**[15]** narration：最后问一句：你被 AI「热心过度」坑过最离谱的一次是啥？评论区聊聊，我挑几个最狠的。
画面：结尾卡，互动问题大字 + 项目名 ponytail / GitHub 可查（不念外链）。
