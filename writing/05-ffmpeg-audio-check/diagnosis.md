# 第 05 课初稿诊断报告（diagnosis.md）

## 1. 字数与篇幅诊断
- 当前中文纯字数：5,474 字；总字符数：14,740 字符。
- 目标区间：6,000 ~ 7,000 纯中文字，最高不超过 9,000 字。
- 扩充方向：
  1. 在第 2 节进一步讲透 `volumedetect` 与 `loudnorm` 的电平标准，以及采样率不一致（44.1kHz 与 48kHz）在后续音画混流阶段引发的音画漂移隐患；
  2. 在第 3 节进一步讲透 `depause` 过程中的音频波形过零点爆音（Click/Pop）现象，以及如何加入毫秒级渐变淡入淡出（afade）解决声音毛刺；
  3. 在第 4 节深度展开 HOW 提示词引导三步法，补充完整的质检 Agent 交互链路与多音字注音补丁的落地实操案例；
  4. 优化长句与名词堆砌，消除 check_style.py 报出的警告。

## 2. 硬禁令与工程教程体风格诊断
- check_style.py 硬禁令命中：0 处。
- 警告命中：11 处（主要为单句超 80 字、个别词汇如“闭环”需换大白话说明）。
- 无花哨标点（无「」、破折号、emoji），无翻案句（“不是……而是……”），无空泛黑话与好评口头禅。
- 每节均包含基于条件式的卡点拦截与降维路径。

## 3. HOW 提示词核心要求核验
- 第一步：提示词引导 AI 封装底层度量工具（ffmpeg / ffprobe 包装器，输出结构化数据）；
- 第二步：客观测试数据封装为结构化信封喂给 AI（包含段落 ID、问题类型、起止时间戳、偏差毫秒）；
- 第三步：质检提示词引导 AI 自动生成修剪、降噪、重对齐的修复参数。
- 诊断结论：三步法结构清晰，需要在终稿中加入更详细的真实输入输出示例与参数推导过程，强化可落地性。
