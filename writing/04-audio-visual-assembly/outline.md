# 课程大纲：声画组装与资产生成：TTS 配音、封面图与多模态素材的自动化生产

## 1. 文案解耦：从前端组件中提取台词清单
### 1.1 为什么配音引擎不能直接读前端 TSX 代码
- 混合形态代码对大模型和 TTS 解析的破坏性：JSX 标签、条件渲染分支、动态变量插值、Tailwind CSS 类名。
- 架构设计原则：视图逻辑与台词文案严格解耦。React 组件专注于画面布局与 CSS 动画，台词由独立的 narrations.ts 数组承载。
- 提取脚本的设计：通过 extract-narrations.ts 静态读取 src/registry/chapters.ts 与各章节 narrations.ts，生成纯净机器可读的 audio-segments.json。

### 1.2 分段文案 JSON 的数据结构规范
- 标准数据信封：chapter、step、text、audio 四元组定义。
- 序号映射契约：1-indexed 步骤序号与 public/audio/<chapter>/<step>.mp3 文件路径的一一对应。
- 单一真实源法则：修改文案必须在组件层完成并重新运行提取，删除对应旧 MP3，禁止在流水线中间环节手动篡改 JSON。
- 静音步骤处理机制：针对纯展示无口播的动画步骤，台词置空，提取脚本跳过生成 TTS 任务，由前端运行时基于估算时长自动等待。

## 2. 高拟真语音合成：接入 tts-dub 与注音覆盖
### 2.1 TTS 服务对接与音色 IP 绑定
- 服务商选型与协议选择：MiniMax T2A v2 与 OpenAI TTS 对比。为什么直调 HTTP API 而非使用 mmx 命令行工具（mmx 命令行参数序列化缺陷导致 pronunciation 数组传参失败）。
- 账号音色管理：通过 list-voices.mjs 按 UUID v1 时间戳提取账号克隆音色，保持全系列声音 IP 一致。
- 配置文件抽象：tts.config.json 的分层设计（provider、voice_id、speed、pitch、normalize、pronunciation、overrides）。

### 2.2 念法规整与字幕源解耦（normalize）
- 技术术语与代码标识符的读音矛盾：query.ts 需要读作 query 点 ts，v1.2.0 需要读作版本一点二点零，2043 需要读作两千零四十三。
- 念法规整机制：normalize 二维数组仅在向 TTS 发送请求前完成文本替换，字幕源与前端界面仍保留干净的代码原始形态。

### 2.3 多音字精细化注音与逐段覆盖（overrides）
- 全局字典的局限：同一个汉字在不同技术术语中的读音冲突（行高 háng 对比执行 xíng；重载 chóng 对比重要 zhòng）。
- 逐段 overrides 语法：在配置中为特定 chapter/step 单独注入 pronunciation 拼音声调数组，实现多音字零污染精准控制。
- 单段语速与音高微调：信息密度过大段落与关键结论段落的语速补偿。
- 同段同字两读的极限情况与文案重构：单段内相同文字多音并存时的唯一正解（重构台词换用无歧义词汇）。

## 3. 批量合成与工程防御：前置探测与容错
### 3.1 为什么批量合成前必须先单段探测余额
- 批量调用的故障成本：批量并发合成数十段音频时遇到 MiniMax 1008 余额耗尽错误，导致大量残缺文件与无效算力消耗。
- 前置探针与熔断机制：在全量任务前发起极短文本探针，验证 API Key 与余额；捕获 1008 状态码后优雅挂起，状态置为 drafting，向控制台与飞书推送充值提醒，阻断后续录屏。

### 3.2 串行合成与指数退避重试
- 网络抖动与接口限流应对：单段合成 3 次重试与 800ms * attempt 指数退避设计。
- 增量合成与状态过滤：文件存在性检查跳过已有音频，结合 --force 全量重刷与 --only 局部补录参数。

## 4. 视觉门面：生成高辨识度的 9:16 竖版封面
### 4.1 平台展示逻辑与横屏截图陷阱
- 抖音主页与推荐流 9:16 竖屏展示特性：16:9 横屏截图导致的上下黑边与字号压缩问题。
- 封面视觉的三大核心要素：顶部胶囊徽章（系列与集数）、中间主体角色与概念图解（高辨识度吉祥物与核心冲突）、底部大字双行标题（痛点白字加亮色主线）。

### 4.2 基于 baoyu-image-gen 锁定参考图（--ref）
- 扩散模型生图的一致性挑战：随机种子漂移导致角色外貌与视觉风格频繁变样。
- 参考图锚定与提示词工程：以首集封面为基准，使用 --ref 参数锁定像素风吉祥物本体、暗黑科技底色与核心配色；结构化编写 cover-prompt.md。

## 5. 多模态质量验收与防退化闭环
### 5.1 自动化质量检查：dubbing-check 与多维体检
- 完整性校验：检查每一个文案分段是否存在对应的 MP3 文件。
- 语速与时长离群值检测：基于字数与音频时长比例计算每秒汉字数，拦截语速异常过快或过慢段落。
- 静音段落扫描：通过 ffmpeg 扫描内部超长无声死区。

### 5.2 状态流转与资产交付清单
- 标准化产物目录规范与交付物清单。
- 常见报错排查矩阵与自愈方案。
