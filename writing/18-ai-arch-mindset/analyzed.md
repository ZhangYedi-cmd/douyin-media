# 材料盘点：第 18 课《AI架构师超级个体心法：从写代码到造系统，一个人就是一支军队》

## 1. 核心论点与支撑材料
- 论点 1：超级个体的本质不是手写代码的速度，而是将模糊现实需求转化为确定性、自动化自愈系统的系统架构能力。
  - 支撑：METR 2024 开发者对照实验数据，没有闭环测试的手工交互导致耗时增加 19%；Norbert Wiener 控制论的监督控制理论。
- 论点 2：四大支柱构成高可用自媒体流水线全景（生产线、治理线、账号大脑、控制平面）。
  - 支撑：本仓库实际运行沉淀数据：21 条真实发布、26 次全自动运转、18 个工程避坑闸口（白屏概率探测、音轨超前1.5s对齐、MiniMax余额1008拦截等）。
- 论点 3：AI 时代系统设计三大铁律（极简技术栈、清晰信任边界、自愈闭环优于神仙提示词）。
  - 支撑：单一真实源 meta.yaml 与 media CLI 设计、选手与裁判解耦、3 轮熔断机制。
- 论点 4：同一套架构心法可无缝迁移至多种业务场景（公众号长文流水线、开源项目代码巡检、行业竞品情报内参）。
  - 支撑：场景映射表、状态机定义、各场景的输入输出契约与人机闸口设计。
- 论点 5：提示词工程向系统工程跃迁的实战 Prompt 方法论。
  - 支撑：顶层设计 Prompt、测试与状态机 Prompt、自省与架构复盘 Prompt 三套完整工程级实战模板。
