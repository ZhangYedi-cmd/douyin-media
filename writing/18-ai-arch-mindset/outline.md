## 1. 复盘全景：我们究竟搭建了一个怎样的系统？
1.1 四大支柱全景架构复盘
- 支柱 1：生产线（pipeline/）: 消费资产、单向向前、停在人审；
- 支柱 2：治理线（harness/）: 保养资产、定时巡检、数据反哺；
- 支柱 3：账号大脑（brain/）: 注入定位、对标基准与人设硬约束；
- 支柱 4：控制平面（console/）: 文件驱动、状态收敛、可视化观察。
- 架构 Mermaid 全景图与数据流解说。
1.2 工业级实战数据复盘：21 条真实发布、26 次全自动运转、18 个工程避坑闸口。
- 实战数据指标表；
- 真实工程避坑点解析（白屏探测、音轨超前、TTS 余额探针等）。
1.3 角色跃迁：从单步搬运工到系统总设计师。
- 聊天框搬运工与闭环架构师的对比；
- 控制论监督控制与人类角色的退后。

## 2. AI 时代的系统设计三大铁律
2.1 铁律 1：极简技术栈（文件即存储，Markdown 即契约，CLI 即接口）
- WHY：纯文本版本管理、零外部重型依赖、按需加载降低上下文消耗。
- 契约设计与 CLI 封装规范。
2.2 铁律 2：清晰的信任边界（创造归模型，测量归脚本，决策归人类）
- WHY：大模型发散能力 vs 确定性脚本测量 vs 人类终审责任。
- 三权分立设计模式与边界划分。
2.3 铁律 3：自愈闭环优于神仙提示词
- WHY：接受随机性，用确定性测试断言与带改法的诊断回传。
- 选手与裁判解耦、3 轮熔断机制。

## 3. 跨场景迁移实战指南：一套心法拓展三类场景
3.1 场景实战 1：微信公众号与技术专栏长文自动化写作与发布闭环
- 流程映射：Markdown 提炼 -> 排版渲染 -> 事实核查 Agent -> 微信草稿箱推送 -> 手机扫码终审发布。
3.2 场景实战 2：开源项目代码质量巡检与自动化重构提议闭环
- 流程映射：定时拉取 PR -> ESLint/Vitest 客观测试 -> Reviewer Agent 出具诊断 -> 自动提 PR 提议 -> 人类 Merge。
3.3 场景实战 3：行业竞品动态追踪与每日智能内参生成闭环
- 流程映射：定时抓取信源 -> 商业价值打分入池 -> 提炼核心结论 -> 推送飞书/钉钉内参。
