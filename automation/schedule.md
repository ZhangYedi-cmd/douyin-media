# 定时调度（生产线）

> 本表只调度**生产线**（选题→创作→出审）；发布是人审后授权。
> **复盘、巡检等治理任务不在这**——它们属治理线 `automation/harness/`，时间驱动、独立调度。
> 实现方式：Claude Code `schedule` / cron agent，入口 prompt 见 `daily-run.md`。

## 拟定时间表（初版，按产能调整）
| 时间 | 任务 | 说明 |
|---|---|---|
| 工作日 08:30 | 选题 | 扫热点+深度源，产出当日 brief，更新选题池 |
| 工作日 09:30 | 创作 | 把当日 brief 做成口播稿/图文+配图 |
| 工作日 11:00 | 出审提醒 | 成品就绪，通知人审 |

> 治理线调度（复盘 24/72h/7d、巡检等）见 `automation/harness/`。
