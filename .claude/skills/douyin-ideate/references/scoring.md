# 抖音版选题打分（双赛道 6 维）

借鉴 Berger STEPPS 传播力模型，但**权重按抖音视频 + AI 技术账号重调**，不照搬图鉴号。
两条赛道用两套权重，因为驱动力不同：深度题靠"有用+看得完"，流量题靠"够新+够炸"。

## 6 个维度（每条候选打 1-5 分）

| 维度 | 问自己 | 5 分长什么样 |
|---|---|---|
| 实用 practical | 看完能不能直接用到工作里？ | 即学即用：一个 prompt/工作流/技巧，明天就能省时间 |
| 社交 social | 转发显不显得"懂 AI、在前沿"？ | "你居然知道这个"，转发有面子 |
| 惊奇 emotion | 是不是"卧槽这也行/反常识"？ | 强烈意外、颠覆认知、FOMO |
| 完播 hook | 前 3 秒抓人吗？撑得住看完吗？ | 钩子炸、有反转/悬念、节奏紧 |
| 时效 timeliness | 是不是当下正热、有人搜？ | 今天的大新闻/刚发布，热度峰值 |
| 触发 trigger | 日常多久会想起这话题？ | 每天写代码/刷 AI 圈都撞得到 |

## 两套权重

**深度赛道（depth）— 重"实用 + 完播"**
```
总分 = 实用×0.30 + 完播×0.25 + 社交×0.15 + 惊奇×0.15 + 时效×0.10 + 触发×0.05
```

**流量赛道（traffic）— 重"时效 + 惊奇"**
```
总分 = 时效×0.30 + 惊奇×0.25 + 完播×0.20 + 实用×0.10 + 社交×0.10 + 触发×0.05
```

> 权重是起步值，按复盘校准：哪类内容实际更火，就把它的强项维度权重往上调。
> v1.1（首次试跑后调）：深度时效 0.05→0.10（旗舰发布的深度实测要趁热）；流量实用 0.05→0.10（"有用的实测"是优质流量题）。

## 打分注意
- **完播无成片时怎么打**：选题阶段还没视频，按"这选题天然有没有悬念/反转/可演示性"估——能边演边讲、有对比悬念的给高分，纯罗列给低分。别脑补成片效果。
- **社交 vs 惊奇别混**：社交=转发给别人"显得我懂"（对外炫耀）；惊奇=自己看到的瞬间"卧槽"（对内情绪）。同一条常一高一低，都给 4 说明没分清。
- **定位契合微调**：算完加权总分后，若属源码/原理/提效这类"立身"深度题，可 +0~0.3 软加成（封顶 +0.3），避免战略沉淀题被纯传播力分数误杀；加成要在 reason 里写明。

## 分级
| 总分 | 级 | 处置 |
|---|---|---|
| ≥4.0 | S | 立即做，冲爆款 |
| 3.5-3.9 | A | 优先排 |
| 3.0-3.4 | B | 可做，需优化角度/钩子 |
| 2.5-2.9 | C | 暂缓，除非找到更好切入点 |
| <2.5 | D | 放弃 |

## 形式判断：口播 还是 图文？

打完分顺手定形式（auto 模式靠这条自动决定）：

| 选 口播 | 选 图文 |
|---|---|
| 观点/态度强（"我认为""最该看的是"） | 清单/对比/排行（"5 个""X vs Y"） |
| 有"我踩过坑"的实操故事 | 信息密度高、适合扫读 |
| 需要语气、节奏带情绪 | 有架构图/流程图能讲清（配 baoyu-diagram） |
| 源码/原理边讲边演示 | 资讯速览、要点罗列 |

判断不了时：**深度题默认口播，流量速览默认图文。**
