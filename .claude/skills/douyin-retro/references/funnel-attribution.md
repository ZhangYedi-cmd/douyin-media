# 漏斗归因模型(复盘的大脑)

复盘的价值不是填数字,是把"数字异常"翻译成"下一条该改什么"。两步:**先定位漏在漏斗哪一环,再查归因表给动作。**

## 一、传播漏斗(抖音推荐机制 = 层层过滤)

```
曝光 ──ctr(封面点击率)──▶ 点进
点进 ──bounce_2s(2s跳出率)──▶ 留下           ← 钩子/封面
留下 ──finish_5s(5s完播率)──▶ 看进去
看进去 ──finish_rate / avg_play_sec──▶ 看完     ← 节奏/内容
看完 ──互动率=(likes+collects+comments+shares)/plays──▶ 被推 ← 价值/共鸣
互动 ──fans_delta / profile_visits──▶ 沉淀       ← 人设/钩子
```

**找漏点的方法**:把每条作品的每一环,与 ① 同类作者百分位(平台给)② 自己历史均值(benchmarks.md)③ 同支柱均值 三个基准比。**最先低于基准的那一环 = 主漏点**,优先归因它,别眉毛胡子一把抓。

## 二、症状 → 病因 → 动作(归因表)

| 症状(相对基准) | 病因 | 下一条动作 | 反哺阶段 |
|---|---|---|---|
| ctr 低 | 封面/标题没勾住 | 改封面文案,首图承担钩子 | 2-create / baoyu-cover-image |
| bounce_2s 高 | 前 3 秒钩子废 | 重写开场 3 秒 | 2-create 钩子清单 |
| finish_5s 低 | 开头铺垫太久 | 前置结论/痛点 | 2-create 口播稿结构 |
| finish_rate / avg_play 低 | 节奏拖、信息密度低、太长 | 压缩时长、卡掉废段 | 2-create 剪辑 |
| 完播 OK 但互动率低 | 有信息没共鸣/无引导 | 加 takeaway、提问、争议点 | 2-create 结尾设计 |
| 互动 OK 但 fans_delta 低 | 单条好看但没人设钩子 | 结尾给关注理由、强化定位 | brain/persona |
| 搜索流量占比高(v2) | 选题踩中搜索需求 | 该类选题加权、标签优化 | 1-ideate / 4-publish |
| 画像没命中 AI 工程师(v2) | 选题/表达跑偏定位 | 修选题方向 | 1-ideate / brain/positioning |

## 三、横切对比(找赛道,不只看单条)
按这些维度分组比均值,找"系统性有效/无效":
- **支柱**:depth(技术深度) vs traffic(流量型)——哪类 ROI 高
- **体裁**:视频 vs 图文、时长档(1min/3-5min/5min+)
- **选题来源**:meta.yaml 的 source 字段
- **发布时段**:对比 4-publish 的时段假设

## 四、回写大脑(闭环)
- `brain/benchmarks.md`:沉淀有效打法 + 刷新各指标"自己历史均值"基线(下次复盘的尺)。
- `brain/sources.md`:产出高表现的信息源打标。
- `brain/positioning.md` / `persona.md`:画像/涨粉异常时才动。
- `content/_backlog/`:评论热词、衍生选题线索入池。

## 五、基线冷启动
首次复盘无历史均值 → 用平台「同类作者百分位」当唯一基线。随复盘积累,benchmarks.md 里的自己历史均值逐步成为主基线(更贴合本账号)。
